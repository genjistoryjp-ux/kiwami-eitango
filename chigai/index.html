まぎらわしい英単語の違い

つづりや意味が似ていて、まちがえやすい英単語236組の違いです。見分けるポイントと例文、入試でどちらがよく出たか、確認問題をのせています。

その単語で始まる組は、まだありません。

ABCDEFGHIKLMNOPQRSTUVW

A

  • accept と exceptaccept は「～を受け入れる」という動詞、except は「～を除いて」という前置詞です。
  • accident と incidentaccident は「（偶然の）事故」、incident は「（注目すべき）出来事・事件」です。
  • acquire と requireacquire は「～を身につける・獲得する」、require は「～を必要とする」です。
  • adapt と adoptadapt は「適応する・合わせて変える」、adopt は「～を採用する・養子にする」です。
  • affect と effectaffect は「～に影響を与える」という動詞、effect は「影響・効果」という名詞です。
  • affluent と fluentaffluent は「裕福な・豊かな」、fluent は「（言葉が）流暢な」です。
  • amaze と amuseamaze は「～をびっくりさせる」、amuse は「～を楽しませる・面白がらせる」です。
  • amend と mendamend は「（法律・文書）を改正・修正する」、mend は「（壊れた物）を直す・繕う」です。
  • ancestor と descendantancestor は「先祖（自分より前の世代）」、descendant は「子孫（自分より後の世代）」です。
  • anonymous と unanimousanonymous は「匿名の」、unanimous は「満場一致の」で、つづりと音が似ています。
  • arise と arousearise は「（問題などが）生じる」という自動詞、arouse は「（感情など）を呼び起こす」という他動詞です。
  • arise と risearise は「（問題・困難などが）生じる」、rise は「上がる・昇る」です。
  • aspire と inspireaspire は「（～を）志す・熱望する」という自動詞、inspire は「～を奮い立たせる」という他動詞です。
  • assemble と resembleassemble は「～を組み立てる・集める」、resemble は「～に似ている」です。
  • assume と resumeassume は「～と思い込む・仮定する」、resume は「～を再開する」という動詞です。
  • attach と attackattach は「～を取り付ける・添付する」、attack は「～を攻撃する」です。
  • attract と distractattract は「～を引きつける」、distract は「（注意など）をそらす」で、向きが逆です。
  • attribute と contributeattribute は「～を…のせい・おかげにする」、contribute は「（～に）貢献する・寄与する」です。
  • award と rewardaward は「（審査で功績に与える）賞・授与する」、reward は「（行いへの）ほうび・報いる」です。

B

  • barely と hardlybarely は「かろうじて～する」で肯定寄り、hardly は「ほとんど～ない」という否定の語です。
  • bend と bindbend は「～を曲げる・曲がる」、bind は「～を縛る・結びつける」です。
  • besides と exceptbesides は「～に加えて」と足す語、except は「～を除いて」と引く語です。
  • boast と boostboast は「自慢する」、boost は「～を押し上げる・高める」です。
  • borrow と lendborrow は「（人から）～を借りる」、lend は「（人に）～を貸す」です。

C

  • cite と sitecite は「～を引用する・挙げる」という動詞、site は「用地・現場」という名詞で、発音は同じです。
  • classify と clarifyclassify は「～を分類する」、clarify は「～を明らかにする・はっきりさせる」です。
  • coincide と collidecoincide は「同時に起こる・一致する」、collide は「衝突する」です。
  • compete と completecompete は「競争する」という自動詞、complete は「～を完成させる」「完全な」です。
  • competent と competitivecompetent は「有能な・能力のある」、competitive は「競争の激しい・負けず嫌いな」です。
  • complement と complimentcomplement は「～を補う・引き立てる」、compliment は「ほめ言葉・～をほめる」で、発音は同じです。
  • confident と confidentialconfident は「自信のある・確信して」、confidential は「機密の・内密の」です。
  • confirm と conformconfirm は「～を確認する・裏付ける」、conform は「（規則・慣習に）従う、合わせる」です。
  • conscience と consciousconscience は「良心」という名詞、conscious は「意識している・気づいている」という形容詞です。
  • conservation と conversationconservation は「（自然の）保護・保存」、conversation は「会話」です。
  • considerable と considerateconsiderable は「（量・程度が）かなりの」、considerate は「（人が）思いやりのある」です。
  • consist と insistconsist of は「～から成る」、insist on は「～を主張する・言い張る」で、前置詞も意味も違います。
  • constant と consistentconstant は「絶え間ない・一定の」、consistent は「一貫した・矛盾しない」です。
  • contemporary と temporarycontemporary は「現代の・同時代の」、temporary は「一時的な」です。
  • content と contextcontent は「内容・中身」、context は「文脈・背景」です。
  • contract と contrastcontract は「契約（する）・縮む」、contrast は「対照（をなす）・対比（する）」です。
  • curious と furiouscurious は「好奇心の強い・奇妙な」、furious は「激怒した」です。
  • current と currencycurrent は「現在の」「流れ」、currency は「通貨」という名詞です。
  • custom と habitcustom は「（社会の）慣習」、habit は「（個人の）習慣・癖」です。

D

  • decade と decaydecade は「10年間」という名詞、decay は「腐る・衰える」という動詞（名詞も同形）です。
  • defer と differdefer は「～を延期する」という他動詞、differ は「異なる」という自動詞です。
  • delicate と dedicatedelicate は「繊細な・微妙な」という形容詞、dedicate は「～をささげる」という動詞です。
  • deprive と derivedeprive は「（人から）～を奪う」、derive は「～を引き出す・～に由来する」で、前置詞が違います。
  • describe と prescribedescribe は「～を描写する・説明する」、prescribe は「（薬）を処方する・定める」です。
  • deserve と reservedeserve は「～に値する・～を受けて当然だ」、reserve は「～を予約する・取っておく」です。
  • despise と despitedespise は「～を軽蔑する」という動詞、despite は「～にもかかわらず」という前置詞です。
  • destiny と destinationdestiny は「運命・宿命」、destination は「目的地・行き先」です。
  • device と devisedevice は「装置・機器」という名詞、devise は「～を考案する」という動詞です。
  • dissolve と resolvedissolve は「溶ける・～を溶かす」、resolve は「（問題）を解決する・決心する」です。
  • distinguish と extinguishdistinguish は「～を区別する・見分ける」、extinguish は「（火・明かり）を消す」です。
  • disturb と distractdisturb は「（休息・作業・静けさを）邪魔する・乱す」、distract は「（注意を）そらす」です。
  • divert と diversedivert は「（進路・注意）をそらす」という動詞、diverse は「多様な」という形容詞です。
  • doubt と suspectdoubt は「～ではないと思う」、suspect は「～ではないかと思う」です。
  • draft と driftdraft は「下書き・草案」、drift は「漂う・漂流」です。
  • drag と drugdrag は「～を引きずる」という動詞、drug は「薬・麻薬」という名詞です。

E

  • economic と economicaleconomic は「経済の」、economical は「節約になる・安上がりな」です。
  • effective と efficienteffective は「効果的な（よい結果が出る）」、efficient は「効率的な（無駄がない）」です。
  • elaborate と collaborateelaborate は「精巧な」「詳しく述べる」、collaborate は「協力する・共同で取り組む」です。
  • eminent と imminenteminent は「著名な・優れた」、imminent は「（危険などが）差し迫った」です。
  • emit と omitemit は「（光・ガスなど）を放出する」、omit は「～を省く・除外する」です。
  • empathy と sympathyempathy は相手の立場で同じ気持ちを感じる「共感」、sympathy は「同情・思いやり」です。
  • enormous と numerousenormous は「巨大な・莫大な」（大きさ・量）、numerous は「多数の」（数）です。
  • erupt と disrupterupt は「噴火する・勃発する」という自動詞、disrupt は「～を混乱させる」という他動詞です。
  • eternal と externaleternal は「永遠の」、external は「外部の」です。
  • ethical と ethnicethical は「倫理的な・道徳上の」、ethnic は「民族の・民族特有の」です。
  • evaluate と evacuateevaluate は「～を評価する」、evacuate は「（人）を避難させる・避難する」です。
  • evolution と revolutionevolution は「（徐々に進む）進化・発展」、revolution は「（急激な）革命・大変革」です。
  • evolve と involveevolve は「進化する・発展する」という自動詞、involve は「～を含む・巻き込む」という他動詞です。
  • exacerbate と exaggerateexacerbate は「（悪い状況）を悪化させる」、exaggerate は「～を誇張する」です。
  • except と expectexcept は「～を除いて」という前置詞、expect は「～を予期する・期待する」という動詞です。
  • experiment と experienceexperiment は「実験（する）」、experience は「経験（する）」です。
  • expert と exportexpert は「専門家・熟練した」、export は「～を輸出する・輸出（品）」です。
  • explicit と implicitexplicit は「はっきり示された」、implicit は「はっきり言わず暗に示された」で、反対の意味です。
  • explode と exploreexplode は「爆発する」、explore は「～を探検する・調べる」です。
  • express と impressexpress は「（考え・気持ち）を表現する」、impress は「（人）に感銘を与える」です。
  • extend と extentextend は「～を延長する・広げる」という動詞、extent は「程度・範囲」という名詞です。

F

  • facility と facultyfacility は「施設・設備」、faculty は「（心身の）能力」「（大学の）学部・教員」です。
  • fair と farefair は「公平な」「見本市」、fare は「（乗り物の）運賃」で、発音は同じです。
  • favor と flavorfavor は「親切な行為・好意」や「～を支持する」、flavor は「風味・味」です。
  • fiction と frictionfiction は「小説・作り話」、friction は「摩擦・不和」です。
  • flourish と nourishflourish は「繁栄する・よく育つ」という自動詞、nourish は「～に栄養を与える」という他動詞です。
  • fond と fundfond は「～を好んで」という形容詞、fund は「資金・基金」という名詞で、動詞にもなります。
  • foresee と overseeforesee は「～を予見する・見越す」、oversee は「～を監督する・監視する」です。
  • formal と formerformal は「正式の・形式ばった」、former は「以前の・元の」「前者」です。
  • former と latterformer は「前者（の）・以前の」、latter は「後者（の）・後半の」です。

G

  • gaze と glancegaze は「じっと見つめる」、glance は「ちらっと見る」で、見る時間の長さが違います。
  • gender と genregender は「（社会的な）性・性別」、genre は「（芸術の）ジャンル」です。
  • gradual と graduategradual は「徐々の、緩やかな」という形容詞、graduate は「卒業する」「卒業生」です。
  • grief と briefgrief は「深い悲しみ」という名詞、brief は「短い・簡潔な」という形容詞です。

H

  • habit と habitathabit は個人の「習慣・癖」、habitat は動植物の「生息地」です。
  • hardly と seldomhardly は「ほとんど～ない」で程度を、seldom は「めったに～ない」で頻度を表します。
  • haunt と hunthaunt は「（幽霊が）～に出る・（記憶が）つきまとう」、hunt は「狩る・探し回る」です。
  • health と wealthhealth は「健康」、wealth は「富・財産」で、つづりは h と w の1字違いです。
  • humor と rumorhumor は「ユーモア・おかしみ」、rumor は「うわさ」です。

I

  • ideal と idleideal は「理想的な・理想」、idle は「何もしていない・怠けた」です。
  • illuminate と eliminateilluminate は「～を照らす・明らかにする」、eliminate は「～を取り除く」です。
  • immediate と intermediateimmediate は「即座の・直接の」、intermediate は「中間の・中級の」です。
  • immense と intenseimmense は「（大きさ・量が）莫大な」、intense は「（程度・強さが）激しい、強烈な」です。
  • imply と inferimply は話し手が「～をほのめかす」、infer は聞き手が「～を推論する」です。
  • incite と insightincite は「～を扇動する」という動詞、insight は「洞察（力）」という名詞です。
  • income と outcomeincome は「収入・所得」、outcome は「結果・成果」です。in と out で反対の意味にはなりません。
  • incur と occurincur は「（損失・費用）を被る」という他動詞、occur は「起こる」という自動詞です。
  • indigenous と ingeniousindigenous は「先住の・土着の」、ingenious は「巧妙な・独創的な」です。
  • industrial と industriousindustrial は「産業の・工業の」、industrious は「勤勉な」です。
  • inherent と inheritinherent は「固有の・本来備わった」という形容詞、inherit は「～を相続する・受け継ぐ」という動詞です。
  • innovation と inventioninnovation は「（やり方・仕組みの）革新」、invention は「発明・発明品」です。
  • install と instillinstall は「～を設置する・取り付ける」、instill は「（考えなど）を教え込む」です。
  • instinct と distinctinstinct は「本能・直感」という名詞、distinct は「はっきりした・異なる」という形容詞です。
  • intellectual と intelligentintellectual は「知的な・知性の」、intelligent は「知能の高い・頭のよい」です。
  • intention と attentionintention は「意図・つもり」、attention は「注意・注目」です。
  • interpret と interruptinterpret は「～を解釈する・通訳する」、interrupt は「（話など）をさえぎる・中断させる」です。
  • intimate と intimidateintimate は「親密な・詳しい」という形容詞、intimidate は「～を威圧する・脅す」という動詞です。
  • invade と evadeinvade は「～に侵入する・侵略する」、evade は「～を逃れる・避ける」です。
  • invent と discoverinvent は「（新しい物）を発明する」、discover は「（すでにある物）を発見する」です。

K

  • knowledge と acknowledgeknowledge は「知識」という名詞、acknowledge は「～を認める」という動詞です。

L

  • latitude と attitudelatitude は「緯度」「（行動の）自由」、attitude は「態度・考え方」です。
  • lawyer と layerlawyer は「弁護士・法律家」、layer は「層・重なり」です。

  • liable と reliableliable は「～しがちな・責任がある」、reliable は「信頼できる」です。
  • lie と laylie は「横になる」という自動詞、lay は「～を横たえる・置く」という他動詞です。
  • local と rurallocal は「地元の・その土地の」、rural は「田舎の・農村の」です。local は田舎とは限りません。

M

  • moral と moralemoral は「道徳の」「（物語の）教訓」、morale は「（集団の）士気・やる気」です。

P

  • peasant と pleasantpeasant は「（小作）農民」という名詞、pleasant は「楽しい・心地よい」という形容詞です。

「〜でない」の接頭語

in- / im- / il- / ir- の意味

形容詞などの前に付いて「〜でない」という反対の意味を作ります。後ろの文字によって im-, il-, ir- と形が変わります。

意味
〜でない
形
in- im- il- ir-
  • b, m, p の前では im- になります。impossible, immature, imbalance。
  • l の前では il-、r の前では ir- になります。illegal, irregular, irresponsible。
  • invaluable は「価値がない」ではなく「計り知れないほど貴重な」という意味です。
  • 「中へ」の意味の in- とは別物です。income や input の in は否定ではありません。

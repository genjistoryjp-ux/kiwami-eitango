「下に」の接頭語

sub- / sup- / suc- / suf- / sus- の意味

名詞や動詞の前に付いて「下に」「下から」の意味を加えます。

意味
下に
形
sub- sup- suc- suf- sus-
  • subway（地下鉄）、submarine（潜水艦）、subconscious（潜在意識の）。
  • p の前で sup-、c の前で suc-、f の前で suf- になります。support, succeed, suffer。
  • suggest の sug-、sustain や suspend の sus- も sub- の変化形です。
  • support は「下から運ぶ」→「支える」と考えるとつながります。

sub- / sup- が付いてできる単語1語

左が元の単語、右が接頭語の付いた単語です。

  • conscious→subconscious潜在意識の；（the subconscious で）潜在意識

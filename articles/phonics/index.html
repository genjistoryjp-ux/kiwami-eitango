フォニックスのルール一覧｜受験英単語で数えた、つづりと読み方

2026年11月21日

英単語のつづりには、読み方のルールがあります。ルールごとに受験英単語の何語中何語が当てはまるかを数え、信じてよいルールと例外の多いルールを分けました。

この記事のポイント
  • ee・ay・oi や、強く読む「母音字＋子音字＋e」は9割以上がルールどおり
  • ea・ow・oo は読み方が分かれ、強く読まない母音は8割が弱い音になる
  • ルールで音の見当をつけ、単語ページの音声で確かめて覚える
目次
  1. フォニックスのルール早見表
  2. ルール1　母音字1つは、短い音か、名前の音
  3. ルール2　強く読まない母音は、弱い「ア」になりやすい
  4. ルール3　母音字＋r は、別の音になる
  5. ルール4　母音字2つは、組み合わせごとに覚える
  6. ルール5　子音字はほぼつづりどおり。読み方が分かれるのは c・g・s・ch・th・x
  7. ルール6　語尾のまとまりは、決まった音で読む
  8. ルールで読めない語｜黙字、gh・ough、基本語の例外
  9. 単語を覚えるときの使い方
  10. まとめ

フォニックスは、英語のつづりと発音の対応をルールにしたものです。ルールを知っていると、初めて見る単語でも読み方の見当がつき、音といっしょに覚えられます。

先に結論です。

  • 母音字1つは、強く読むところならルールが当たる。強く読まないところは弱い「ア」になりやすい
  • 母音字2つは組み合わせしだい。ee・ay・oi は読み方がほぼ1通り、ea・ow・oo は2通り以上
  • 子音字と ​-⁠tion などの語尾は、ほぼ決まった音で読める。読み方が分かれるのは c・g・s・ch・th・x

このサイトの単語ページにある受験英単語3,467語（見出し語）で、つづりごとに読み方を数えました。音声と発音記号はアメリカ英語です。

数え方：表の「65/71」は、そのつづりをふくむ見出し語71語のうち65語がその音、という意味です。1語は1回だけ数え、uphold（up＋hold）の ph のように語の2つの部分にまたがるつづりは除きました。「本」は、大学入試1,588本と共通テスト12本のうち、その語が出た試験の数です。

ことば：母音字は a・e・i・o・u、子音字はそれ以外の字です。名前の音は、a の「エイ」のような、アルファベットの名前どおりの音です。「強く読む」は、アクセントのある母音（発音記号で ´ のついた母音）のことです。

ルール1　母音字1つは、短い音か、名前の音

母音字1つの読み方は、fact の a のような短い音と、state の a のような名前の音の2つで、おもに、あとに続く字で決まります。

子音字で終わるときは短い音

母音字が1つで、子音字で終わる1音節の見出し語242語で数えました（母音字のあとが r・w・y の語はのぞく）。

つづり音語数例
a/æ/ ア59/66fact, lack
e/e/ エ35/35tend, stress
i/ɪ/ イ66/70skill, risk
o/ɑ/ ア19/30spot, block
u/ʌ/ ア39/41fund, trust

a・e・i・u はほぼルールどおりです。o は30語中11語が外れますが、多くは host のような決まった形です。表の o の19語には、loss のような /ɔː/（オー）の4語もふくみます。

a・o・u の短い音は、カタカナではどれも「ア」です。a は「ア」と「エ」の中間、o は口を大きく開けた「ア」、u は短く軽い「ア」で、つづりが音を見分ける手がかりになります。fond と fund の違いでも確かめられます。

語尾に e がつくと、アルファベットの名前の音

「a＋子音字1つ＋語尾の e」の形では、e は読まず、a を名前の音「エイ」で読みます（マジック e）。i・o・u・e も同じで、表では a-e のように書きます。

つづり音語数例
a-e/eɪ/ エイ60/61state, save
i-e/aɪ/ アイ75/83provide, decide
o-e/oʊ/ オウ40/45role, note
u-e/uː/ ウー・/juː/ ユー38/38include, huge
e-e/iː/ イー16/17complete, extreme
94%強く読む「母音字＋子音字1つ＋e」が、名前の音で読まれる割合（244語中229語）

つまり、その母音を強く読む語なら、この形は信じてよいルールです。​-⁠age や ​-⁠ate のように語尾を強く読まない語は、ルール2で見ます。

u-e は、l・r・d・s・z のあとならほぼ /uː/（reduce）、それ以外なら /juː/（confuse）でした。

例外は15語です。prove・improve・remove などは o-e を /uː/（ウー）、routine・vaccine・elite などは i-e を /iː/（イー）と読みます。

基本語には、have、come、give のような例外があります。英語ではふつう v で語を終えないので、have や give の e は v のあとを埋める字で、母音の読み方は変えません。

子音字が重なると、前の母音は短い音

強く読む母音字のすぐあとに、同じ子音字が2つ続く形（tt・ss など）と、ck・tch・dge が続く形を数えました。245語のうち234語が短い音です（matter、effort、common）。

later（レイター）と latter（ラター）のように、子音字が1つか2つかで母音が変わります。stop → stopped と子音字を重ねて書くのは、母音を短いまま読ませるためです。

子音字1つをはさむときは、つづりだけでは決まらない

強く読む母音字のあとが「子音字1つ＋母音字」のときは、短い音にも名前の音にもなります。後ろから2番目の音節を強く読む251語（​-⁠ation などの形と複合語をのぞく）では、短い音が147語、名前の音が98語、ほかの音が6語でした。

  • label（レイベル）と habit（ハビット）
  • item（アイテム）と limit（リミット）

見当がつくのは、​-⁠ation・​-⁠ial・​-⁠ious のように「子音字＋i・e＋母音字」が続く形です。

  • a・e・o・u は名前の音：137語中127語（nation、social、region）。例外は precious（プレシャス）や rational（ラショナル）などで、基本語の special も短い音
  • i は短い音：54語すべて（condition、decision）

短い音にならない、決まった形

子音字で終わっていても、次の形は短い音になりません。

つづり音語数例
​-⁠old・​-⁠ost・​-⁠oll/oʊ/ オウ21/22fold, enroll
​-⁠ind・​-⁠ild/aɪ/ アイ12/13remind, mild
w・qu＋a/ɑ/ ア11/12quality, wander
​-⁠all・​-⁠alk・​-⁠alt/ɔː/ オー9語recall, install

例外は、​-⁠ost の frost、w＋a の watery（どちらも /ɔː/）、​-⁠ild の wilderness（/ɪ/）です。基本語の cost・lost も /ɔː/ で、most・host の /oʊ/ と分かれます。control の ​-⁠rol も ​-⁠oll の仲間で、コントロウル です。find、old、all、want など、基本語にも多い形です。

もう1つ、o を /ʌ/（ア）と読む語があります。強く読む o のあとに m・n・v・th が続く134語のうち19語で、government、discover、wonder、cover などです。基本語の come、money、month、front（フラント）も同じです。wander（/ɑ/）と wonder（/ʌ/）は、カタカナではどちらも「ワンダー」です（wander と wonder の違い）。

ルール2　強く読まない母音は、弱い「ア」になりやすい

81%2音節以上の見出し語で、いちばん強く読む母音以外の母音が、弱い音になる割合（4,857個中3,921個）

弱い音は、力を抜いた「ア」の /ə/ と /ər/、それに弱い「イ」「ウ」です。

/ə/ には決まったつづりがありません。allow の a、system の e、reason の o、support の u は、どれも /ə/ です。

ルール1やこのあとのルールが当てはまるのは、強く読む母音です。

残りの2割ほどは、はっきりした音のままです。indicate の ​-⁠ate や organize の ​-⁠ize のように、2番目に強く読むところ（発音記号で ` の母音）に多く見られます。

同じ語尾でも、強く読むかどうかで音が変わる

語尾に e がつく形でも、語尾を強く読まない語は、名前の音にならないことがよくあります。ただし indicate のように語尾を2番目に強く読む語は、名前の音のままです。

つづり音語数例
​-⁠age/ɪdʒ/ イッジ21/24average, damage
​-⁠age/eɪdʒ/ エイジ3/24engage, wage
​-⁠ate/ət/ 弱いエット27/162climate, private
​-⁠ate/eɪt/ エイト135/162indicate, create
​-⁠ive/ɪv/ イヴ38/50negative, positive
​-⁠ive/aɪv/ アイヴ11/50arrive, survive
​-⁠ine/ən/ 弱いイン11/37imagine, determine
​-⁠ine/aɪn/ アイン19/37decline, define

​-⁠ine の残り7語は、routine のような /iːn/（イーン）です。​-⁠ice や ​-⁠ite も同じように分かれます（practice と advice、opposite と despite）。

つまり、語尾をいちばん強く読む語は名前の音になります（​-⁠age・​-⁠ate・​-⁠ive・​-⁠ine など17種類の語尾を合わせて、126語中117語）。e のルールの例外に見える語の多くは、語尾を弱く読む語です。

品詞で読み方が変わる語

​-⁠ate で終わる2音節以上の語は、動詞なら /eɪt/（129語すべて）、形容詞なら弱い /ət/ です（23語中22語）。名詞は、climate のような /ət/ と、debate・candidate のような /eɪt/ に分かれます。separate は、形容詞が セパレット、動詞が セパレイト です。

強く読む位置が変わる語もあります。increase は、名詞が インクリース、動詞が インクリース です。同じ語で名詞と動詞の強く読む位置が変わる見出し語35語は、すべて名詞が前、動詞が後ろでした。単語ページの発音記号と音声は、どちらか一方の読み方です。

語尾によって強く読む位置が決まる語は、派生語の記事で取り上げています。

ルール3　母音字＋r は、別の音になる

母音字のあとに r が続くと、短い音でも名前の音でもない音になります。強く読む「母音字＋r」のあとに子音字が続くか、そこで語が終わる見出し語で数えました。

つづり音語数例
ar/ɑːr/ アー69/71argue, harm
or/ɔːr/ オー53/54support, force
er/əːr/ アー77/77term, concern
ir/əːr/ アー10/10confirm, firm
ur/əːr/ アー34/34occur, urban

w のあとをのぞく246語のうち243語が表のとおりです。例外は scarcity・scarcely（/eər/）と attorney（/əːr/）でした。強く読まないところでは、consider や author のように弱い /ər/ になります。

「アー」は2種類ある

ar は口を大きく開けた /ɑːr/、er・ir・ur は口をあまり開けない /əːr/ です。カタカナではどちらも「アー」で、farm と firm は「ファーム」、star と stir は「スター」です。「アー」は、つづりが ar なら /ɑːr/、er・ir・ur（ear＋子音字や wor も）なら /əːr/ と見分けましょう。

w のあとは入れ替わる｜war は「ウォー」、wor は「ワー」

  • war は /wɔːr/（ウォー）：warn、award、reward など9語すべて。基本語の war、warm も同じ
  • wor は /wəːr/（ワー）：worth、worship など5語すべて。基本語の work、world、word も同じ

award は「アワード」ではなく アウォード です。例外は sword（ソード。w も読みません）と、wear の過去形・過去分詞の wore・worn（ウォー）です。

work を「ウォーク」と読むと、walk に聞こえます。

are・ore・ire などは決まった音。ear と our は語ごとに確かめる

つづり音語数例
are・air/eər/ エア20/20share, repair
ore・oar/ɔːr/ オー17/17store, soar
ire/aɪər/ アイア13/13require, desire
ere・eer/ɪər/ イア16/17severe, career
強く読む ure​-⁠ture をのぞく/ʊər/ ウア・/jʊər/ ユア11/11ensure, secure
弱い ure/ər/ 弱いアー32/33measure, pressure
ear＋子音字/əːr/ アー8/10search, earn
語尾の ear/ɪər/ イア11/13appear, gear

例外：elsewhere（/eər/。基本語の there も同じ）、bear（/eər/）、heartbreak（/ɑːr/）など。

career（カリア）や volunteer（ヴァランティア）は語尾の eer を強く読み、カタカナ語とは強く読む位置がちがいます。

our には決まった読み方がなく、source は /ɔːr/、journey は /əːr/、基本語の hour は「アウア」です。very や carry のように r のあとに母音字が続く語も、決まりません。

ルール4　母音字2つは、組み合わせごとに覚える

「母音字が2つ並んだら、1つめを名前の音で読む」という覚え方があります。explain の ai は「エイ」、goal の oa は「オウ」です。

52%この覚え方が当たる割合（母音字2つをまとめて強く読む見出し語477語中247語）

ただし、組み合わせごとに見ると、読み方がほぼ決まるものがあります。

読み方がほぼ1つの組み合わせ

つづり音語数例
ee/iː/ イー54/54seem, degree
ay/eɪ/ エイ21/21display, delay
igh/aɪ/ アイ20/20flight, insight
ew・ue/uː/ ウー・/juː/ ユー28/28crew, due
oi・oy/ɔɪ/ オイ25/26avoid, destroy
au・aw/ɔː/ オー42/45cause, law
ai/eɪ/ エイ65/71explain, remain
oa/oʊ/ オウ13/16approach, goal

oa は broad・abroad・broadcast が /ɔː/ です。ai は certain・bargain など、強く読まない6語が弱い音になります。語尾の ​-⁠ain は、強く読めば26語すべて /eɪn/ でした。

基本語では、said（セッド、1,029本）と again（アゲン、620本）が ai の例外です。

表にない読み方もあります。

  • ea の /eɪ/：breakthrough など break のつく5語。基本語の great、break も同じ
  • oo の /ʌ/：flood と bloody
  • ow の /ɑ/：knowledge と acknowledge。slowdown は /oʊ/ と /aʊ/ の両方をふくむ

ou は our・ough・​-⁠ous をのぞいた数で、見出し語では9割近くが /aʊ/ です。ただし基本語の country・young は /ʌ/、group は route と同じ /uː/ です。

つづりの形で見当がつくものもあります。

  • ​-⁠ound・​-⁠ount は /aʊ/：23語中22語（surround、account）
  • ow＋n は /aʊ/ が多い：11語中10語（crown、drown）。ただし own と、known・grown・shown・thrown は /oʊ/
  • 2音節以上の語で、強く読まない語尾の ​-⁠ow は /oʊ/：shallow、swallow など8語すべて
  • oo＋k は /ʊ/：hook、overlook。基本語の book、look も同じ

語の中の ie を1つの音ではっきり読むときは /iː/ です（field、achieve など19語すべて）。ただし view・review のように w が続く iew は /juː/（ユー）で、基本語の friend（フレンド）も例外です。create や society のように母音字を別々に読む語は、数えていません。

似たつづりの語は、threat と treat の違い、route と root の違いでも確かめられます。

ルール5　子音字はほぼつづりどおり。読み方が分かれるのは c・g・s・ch・th・x

b・d・f・h・j・k・l・m・n・p・r・t・v・w・z の15字は、1字で書かれた10,010か所（重なる字や sh などの中の字はのぞく）の97%が、字ごとに決まった音でした。残りの4分の3は ​-⁠tion や ​-⁠ture などの t です。sh は /ʃ/、ck は /k/、ph は /f/（physical）、tch は /tʃ/ で、見出し語ではどれも例外がありません。

つづり音語数例
c＋e・i・y/s/ ス245/245century, policy
ほかの c/k/ ク704/705culture, focus
cc＋e・i/ks/ クス9語accept, success
g＋e・i・y/dʒ/ ジ127/137energy, region
ch/tʃ/ チ56/84challenge, reach
ch/k/ ク26/84technology, chemical
qu/kw/ クウ42/45require, equal
x/ks/ クス75/80expect, complex
ex＋母音字/gz/ グズ13/13exist, examine
ng＋e・i・y/ndʒ/ ンジ19/21range, exchange

c＋i・e のあとに母音字が続く social・species・efficient などの25語は、/ʃ/（シュ）と読むので表の数に入れていません。

c は信じてよいルールです。g も9割は当たりますが、target・eager など10語の例外があり、基本語の get、give、begin も例外です。

x は、語頭の ex のあとの母音を強く読むとき /gz/ になります（表の「ex＋母音字」）。

ch の /k/ は、tech-・psych-・chem- や ch＋r（chronic）のように、入試レベルの語に多い読み方です。/ʃ/ と読むのは machinery と cliche の2語で、machine と同じです。

s は、ss なら /s/ です（88語中85語。issue のような /ʃ/ の20語はのぞく）。母音字＋se は、cause・rise のような /z/ が67語中46語、increase・purpose のような /s/ が21語で、つづりでは決まりません。advice と advise のように、名詞が c で /s/、動詞が s で /z/ の組もあります（device と devise の違い）。

th は2つの音。にごるのは ​-⁠ther- と the・this の仲間

th を1つの音で読む見出し語95語では、にごらない /θ/ が72語、にごる /ð/ が23語でした。カタカナでは「ス」「ズ」としか書けませんが、位置で見当がつきます。

  • 語頭の th は /θ/：26語中22語（theme、threat）。/ð/ は therefore・thus など4語。基本語の the・this・that も /ð/
  • ​-⁠ther- は /ð/：whether、rather など9語すべて
  • 語尾の ​-⁠th は /θ/：16語中15語（health、growth。例外は smooth）
  • 語尾の ​-⁠the は /ð/：breathe、bathe など4語すべて

ルール6　語尾のまとまりは、決まった音で読む

つづり音語数例

例外は equation（/ʒən/）と congestion（/tʃən/。基本語の question も同じ）です。attention（/əténtʃən/）のような n のあとの /tʃən/ は、ション に数えました。r のあとの ​-⁠sion は、version のように /ʒən/ になります。​-⁠ture は語尾を強く読まない語で数え、例外は miniature（/tʃʊər/）です。

​-⁠ique は /iːk/（イーク）で、語尾を強く読みます（technique、unique）。​-⁠gue は ue を読まず /g/ です（colleague、vague。例外は argue）。

u を弱く読むところでは、t が「チュ」、d が「ジュ」になることが多くあります（natural、education）。attitude や substitute のように u をはっきり読む ​-⁠tude・​-⁠tute は、アメリカ英語では「トゥ」のままです。

​-⁠ed の読み方は、すぐ前の音で決まります。t・d のあとは /ɪd/（wanted）、k・p・s のように声を出さない音のあとは /t/（worked）、それ以外は /d/（played）です。

​-⁠tion・​-⁠sion・​-⁠cial・​-⁠cious などの語尾は、強く読む位置も決めます。見出し語では例外がなく、どれも語尾のすぐ前の母音を強く読んでいました。

語尾の y は「イ」。​-⁠fy と apply・rely の仲間は「アイ」

2音節以上の語の語尾の y は、強く読まなければ「イ」です（​-⁠fy をのぞく316語中314語。likely、ability）。

「アイ」になるのは、​-⁠fy で終わる動詞（identify、satisfy など17語すべて）と、語尾を強く読む語です（apply、rely、deny など11語すべて）。try や fly のような1音節の基本語も「アイ」です。

ルールで読めない語｜黙字、gh・ough、基本語の例外

読まない文字（黙字）

つづりにあっても読まない文字を、黙字といいます。見出し語では少ないので、形ごとに語をあげます。

つづり黙字語数例
kn-k2語knit, knowledge
wr-w4語wrap, wrinkle
ps-p3語psychology, psychiatrist
語頭の hh3語honest, honor
語尾の gng8語design, foreign
語尾の mbb4語limb, tomb
btb3語debt, subtle
​-⁠alk・​-⁠alm などl6語calm, folk
​-⁠stlet3語wrestle, hustle

基本語にも同じ形があります。know、write、talk、climb、castle などです。

gn と mb は、語尾では g・b を読みませんが、語の中では両方読みます（signal、ignore など gn の17語すべて、combine など mb の24語すべて）。ただし assignment のように ​-⁠ment などがついた形では読みません。

読まない文字が、仲間の語では読まれることもあります。design（ディザイン）→ designate（デズィグネイト）、doubt（ダウト）→ dubious（ドゥービアス）などです。仲間の語を思い出すと、読まない文字のつづりを覚えやすくなります。

gh はふつう読まない。ough は読み方が5通り

母音字のあとの gh は、ふつう読みません。gh のある見出し語36語のうち34語がそうでした（highly、weight）。/f/ と読むのは tough・roughly の2語で、基本語では enough、laugh も /f/ です。

ough は見出し語9語で読み方が5通りあり（基本語の cough を入れると6通り）、1語ずつ覚えます。

  • /oʊ/ オウ：although、thorough。基本語の though も同じ
  • /uː/ ウー：throughout、breakthrough。基本語の through も同じ
  • /ʌf/ アフ：tough、roughly。基本語の enough も同じ
  • /ɔː/ オー：ought、thoughtless。基本語の thought も同じ
  • /aʊ/ アウ：drought

似た語は、thorough と throughout の違いでも確かめられます。

単語を覚えるときの使い方

  1. 新しい単語は、強く読む位置を先に確かめる
  2. 強く読む母音にルールを当てて読んでみる。ほかの母音は軽く「ア」と読む
  3. 単語ページの音声で答え合わせをする。ちがっていたら、例外として声に出して覚える
  4. カタカナで知っている語と、読まない文字のある語は、つづりを見ながら声に出す

入試では、リスニングと書くときのつづりに役立つ

1つめはリスニングです。カタカナの音で覚えた単語は、英語の音で読まれると気づきにくくなります。virus は「ウイルス」ではなく ヴァイラス、allergy は「アレルギー」ではなく アラジー です。ほかの例は、英単語の覚え方の記事にあります。

2つめは、書くときのつづりです。子音字を重ねるかどうかや読まない文字は、ルールを知っていると覚えやすくなります。

共通テストでは、発音やアクセントだけを問う問題は出されていません。一部の私立大学では今も出るので、志望校の過去問で確かめてください。

まとめ

  • 強く読む「母音字＋子音字1つ＋e」は、244語中229語（94%）が名前の音
  • 強く読まない母音は、81%が弱い音。ルールは強く読む母音に当てる
  • 母音字＋r は、ar が /ɑːr/、er・ir・ur が /əːr/。w のあとは war が「ウォー」、wor が「ワー」

  • 子音字15字は97%が決まった音。​-⁠tion・​-⁠ture などの語尾も、まとまりで決まった音になる
  • よく出る例外は、have や come のような中学で習う基本語

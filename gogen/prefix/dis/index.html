「反対・〜でない」の接頭語

dis- / di- / dif- の意味

動詞・名詞・形容詞の前に付いて、反対の意味や「〜でない」の意味を作ります。もとは「離れて」という意味です。

意味
反対・〜でない
形
dis- di- dif-
  • agree → disagree、appear → disappear のように反対語を作ります。
  • disease（病気）は dis + ease（楽な状態）で「楽でない状態」から来ています。
  • discover は dis + cover で「覆いを取る」→「発見する」です。
  • di- や dif- の形もあります。direct, differ。distance では「離れて」の意味が残ります。

dis- / di- が付いてできる単語18語

左が元の単語、右が接頭語の付いた単語です。

  • appear→disappear動詞消える、見えなくなる
  • belief→disbelief名詞信じられない気持ち、不信
  • advantage→disadvantage名詞不利な点、欠点
  • connect→disconnect動詞～の接続を切る
  • similar→dissimilar形容詞似ていない、異なる（not dissimilar to ～ ～と似ていなくもない）
  • ability→disability名詞障害
  • continue→discontinue動詞～を中止する、（製造・販売など）を打ち切る
  • prove→disprove動詞～の誤りを証明する、～を反証する
  • agreement→disagreement名詞意見の相違、不一致
  • courage→discourage動詞～の気をくじく、やめさせる
  • honest→dishonest形容詞不正直な、不誠実な
  • approve→disapprove動詞～に反対する
  • respect→disrespect名詞無礼、軽視；（動詞）軽んじる
  • trust→distrust名詞不信（感）；（動詞）信用しない
  • obey→disobey動詞～に従わない、背く
  • grace→disgrace名詞不名誉、恥
  • agree→disagree動詞意見が合わない、反対する
  • respectful→disrespectful形容詞無礼な、失礼な

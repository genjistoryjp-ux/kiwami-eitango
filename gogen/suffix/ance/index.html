名詞を作る接尾語

-ance / -ence / -ancy / -ency の意味

動詞や -ant / -ent の形容詞のうしろに付いて名詞を作ります。「〜すること」「〜であること」を表します。

意味
〜すること・〜であること
品詞
名詞を作る
形
-ance -ence -ancy -ency
  • -ant なら -ance、-ent なら -ence です。abundant → abundance、absent → absence。
  • 動詞からも作ります。accept → acceptance、appear → appearance、annoy → annoyance。
  • -ancy / -ency の形もあります。pregnant → pregnancy、urgent → urgency。

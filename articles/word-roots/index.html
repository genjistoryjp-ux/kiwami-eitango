語根で覚える英単語｜入試に多い20の語根と、まぎらわしい語の見分け方

2026年11月21日

接頭語と接尾語のあいだにある、単語の中心の部品が語根です。このサイトで語源をのせている約1,600語から語根を数え、大学入試によく出る語をたくさん持つ20個を選びました。

この記事のポイント
  • 上位20の語根を持つ見出し語は327語。入試1本に、そのうち31語（中央値）が出ていた
  • 語根はつづりが変わる。receive と reception の ceive／cept のような形を知っておく
  • 語源の分かる違いページ143組の半分以上は、2語の語根が同じ。接頭語のちがいで見分けられる
目次
  1. 見出し語10語以上に共通する語根、上位20個
  2. 同じ語根でも、つづりは変わる
  3. 違いページの組を語根で見分ける
  4. 語根だけで意味を決めないほうがよい語
  5. 語根の覚え方

英単語は、前に付く部品（接頭語）、うしろに付く部品（接尾語）、そして真ん中の部品でできています。この真ん中の部品が語根です。respect なら re（振り返って）＋ spect（見る）、maintain なら main（手）＋ tain（保つ）のように、語根が単語の意味の中心になります。

接頭語と接尾語は接頭語・接尾語の一覧と派生語の記事にまとめました。この記事では残りの語根を扱います。

このサイトでは約1,600語の見出し語に語源をのせていて、語源の欄で語を部品に分けています。そこで、同じ語根を持つ見出し語が何語あるかを数えると、10語以上に共通する語根は26個ありました。その語根を持つ語が大学入試（2020〜2026年度、国公立・私立の英語1,588本）に何本出たかを足し、多い順に20個を選んだのが下の表です。

1本は試験問題1回分のことです。語ごとの本数は、その語（​-⁠s、​-⁠ed、​-⁠ing などの形もふくむ）が1回でも出てきた試験の数です。

「見出し語」は、その語根を語源の欄で持っている見出し語の数です。「延べ本数」は、その見出し語それぞれが出た本数を足した数で、fact と effect が両方出た試験は2本と数えています。語根の意味は、語源の欄でいちばん多く使っている言い方にしました。fac と part は、2つの言い方を並べています。

20個の語根を持つ見出し語は、重なりを除いて327語です。大学入試1,588本のうち、この327語のどれも出てこなかった試験は5本だけでした。

31語入試1本に出てくる、327語のうちの語数（中央値）

入試1本の中に、20個の語根のどれかを持つ語が、ちがう語で30語ほど出てくるということです。語根を20個知っておけば、これだけの語に意味の手がかりができます。

なお、vid と spect はどちらも「見る」、sta と sist はどちらも「立つ」です。sist は sta と同じところから出た形なので、意味もそのまま「立つ」で覚えて大丈夫です。

同じ語根でも、つづりは変わる

語根は、いつも同じつづりで出てくるわけではありません。語源の欄で同じ語根に分けた部分のつづりを集めると、おもな形は次のとおりです。

語根おもな形例
fac作る・行うfac, fact, fect, fic, fit, featfact, effect, efficient, benefit, feature
fer運ぶfer, late, latoffer, relate, relative
cept取るcept, ceive, cip, cap, captconcept, receive, participate, capable, capture
cede行くcede, ceed, cess, ced, cestprecede, succeed, process, procedure, ancestor
ten保つtain, tinue, tent, tinmaintain, continue, content, continent
vid見るvid, vide, vise, vis, viewevidence, provide, advise, vision, review
plic折るplic, ply, ploy, playcomplicated, apply, employ, display
mit送るmit, miss, miseadmit, permission, promise

形がいちばん多い fac は、fact のように見てすぐ分かる形のほかに、efficient の fic、benefit の fit、feature の feat があります。benefit が「よく（bene）行う（fit）こと」と分かれば、利益・恩恵という意味は覚えやすくなります。

動詞と名詞で形が入れかわる語根

受験で特に役に立つのは、動詞と名詞で語根のつづりが規則的に入れかわる組です。動詞を知っていれば、名詞形を長文で見たときに同じ語だと気づけます。

  • ​-⁠ceive → ​-⁠cept-：receive → reception、perceive → perception、deceive → deception
  • ​-⁠ceed／​-⁠cede → ​-⁠cess：succeed → success、exceed → excess、recede → recession
  • ​-⁠tain → ​-⁠ten-：maintain → maintenance、retain → retention
  • ​-⁠mit → ​-⁠miss-：admit → admission、permit → permission、emit → emission
  • ​-⁠tend → ​-⁠tent／​-⁠tens-：extend → extent・extension、intend → intention、attend → attention
  • ​-⁠duce → ​-⁠duct：produce → product、reduce → reduction、introduce → introduction

perceive は175本、名詞の perception は133本で、どちらもよく出ます。emit と emission では、名詞の emission（133本）のほうが、動詞の emit（58本）の倍以上の試験に出ていました。動詞を覚えるときは、名詞の形もいっしょに見ておくと長文で迷いません。

違いページの組を語根で見分ける

このサイトのまぎらわしい英単語の違いは236組あります。そのうち2語とも語源をのせている組は143組で、その半分以上は2語の語根が同じ組でした。最初の接頭語が同じで語根がちがう組も、20組以上あります。

語根が同じ組は接頭語のちがいを、接頭語が同じ組は語根のちがいを見れば、2語の意味の差が分かります。

語根が同じで、接頭語がちがう組

consist・insist・resist（sist＝立つ）は3語とも同じ語根です。

  • consist：con（共に）立つ → まとまって成り立つ → 「～から成る」（174本）
  • insist：in（上に）立つ → 一つの考えに立ち続ける → 「主張する」（152本）
  • resist：re（逆らって）立つ → 押す力に立ち向かう → 「抵抗する」（96本）
  • The team consists of five engineers and two designers.（そのチームは5人のエンジニアと2人のデザイナーから成る）
  • He insisted that he was innocent.（彼は自分は無実だと言い張った）

くわしくはconsist と insist の違い、resist と insist の違いにあります。

prefer と refer（fer＝運ぶ）も接頭語だけがちがいます。prefer は pre（前に）運ぶ、つまり「ほかより前に置く」ので「～のほうを好む」です。refer は re（元へ）運ぶ、「話や注意をそこへ向ける」ので「言及する・参照する」になります。prefer は334本、refer は459本で、どちらも入試によく出ます。prefer と refer の違いでは、prefer A to B と refer to A の形も比べています。

oppose と propose（pos＝置く）は、op（向かいに）置くか、pro（前に）置くかのちがいです。相手の向かいに身を置けば「反対する」、考えを人の前に出せば「提案する」です（oppose と propose の違い）。

  • Many residents opposed the plan for a new airport.（多くの住民が新空港の計画に反対した）
  • She proposed a new plan to the team.（彼女はチームに新しい計画を提案した）

precede と proceed（cede＝行く）は、pre（前を）行くと pro（前へ）行くのちがいです。precede は「先に立つ」、proceed は「そのまま先へ進む」です。つづりは precede が ​-⁠cede、proceed が ​-⁠ceed で、​-⁠ceed で終わる語はふつう proceed・exceed・succeed の3つだけなので、この3つを覚えておけばつづりでも迷いません（precede と proceed の違い）。

ほかにも、attract と distract（tract＝引く：at「～へ」引く／dis「離れて」引く）、recur と occur（cur＝走る：re「戻って」走る／oc「～に向かって」走る）、accept と except（cept＝取る：ac「～へ」取る／ex「外へ」取る）、affect と effect（fac＝作る・行う：af「～へ」／ef「外に」）が同じ型です。

接頭語の意味は、con-／com-、ex-、re-、pro-などのページで、その接頭語を持つ語といっしょに確かめられます。

接頭語が同じで、語根がちがう組

except と expect は、どちらも ex（外へ）で始まります。ちがうのは語根で、except は cept（取る）、expect は spect（見る）の s が落ちた pect です。

  • except：外へ取り出す → 数に入れない → 「～を除いて」（242本）
  • expect：外を見る → 来るものを見張って待つ → 「予想する・期待する」（670本）
  • Everyone came to the party except Tom.（トム以外は全員パーティーに来た）
  • I didn't expect so many people to come.（こんなに大勢の人が来るとは予想していなかった）

except は前置詞として使うことが多く、expect は動詞なので、文の中の位置でも見分けられます（except と expect の違い）。

imply と infer も、in-（中へ）が同じで語根がちがう組です。imply の im- は、in- が p の前で変わった形です。imply は ply（折る）で「言葉の中に意味を折り込む」、infer は fer（運ぶ）で「運び込む」、そこから「根拠から結論を導き出す」です。意味を込めるのが話し手（imply）、受け取って推し量るのが聞き手（infer）と整理できます（imply と infer の違い）。

語根も接頭語も同じで、品詞がちがう組

extend と extent は、ex（外へ）＋ tend（伸ばす）で部品は同じです。ちがうのは最後の1字で、extend は「延長する、広げる」という動詞、extent は「どこまで伸びたかの範囲」から「程度・広さ」という名詞です。上の「​-⁠tend → ​-⁠tent」の入れかわりと同じです。

例：To what extent do you trust him?（あなたは彼をどの程度信頼していますか）

to what extent（どの程度）や to some extent（ある程度）の形でよく使います。extent を見たら名詞だと決めて読めます（extend と extent の違い）。

語根だけで意味を決めないほうがよい語

語根は便利ですが、それだけで意味を決めると外れる語もあります。

同じつづりでも、別の語根

apply と supply は、どちらも ply で終わります。ところが語源では、apply の ply は「折る」（plic）、supply の ply は「満たす」（ple）で、別の語根です。supply は「下から満たす」、つまり「足りない分を補う」から「供給する」になりました。

compare と appear も、つづりの似た pare と pear が別の語根です。compare の pare は「等しい」で、「等しいものとして並べる」から「比べる」になりました。appear の pear は「見えてくる」で、「見えるところへ出てくる」から「現れる」です。つづりが似ていても、語源の欄で語根の意味を確かめてから覚えてください。

語根の意味から、今の意味まで遠い語

語根の意味と今の意味のあいだに、1段か2段はさまる語もあります。

  • suppose：下に（sup）置く → 考えの土台として仮に置く → 「思う・仮定する」
  • suffer：下から（suf）運ぶ → 重荷に耐える → 「苦しむ」
  • pretend：前に（pre）伸ばす → 口実として持ち出す → 「～のふりをする」
  • despite：下に（de）見る → 相手を見下してものともしない → 「～にもかかわらず」

despite は spect（見る）の仲間ですが、spite の形からは気づきにくい語です。こうした語は、語根から意味を当てるより、まん中の「つまり」の段をいっしょに覚えるほうが確実です。このサイトの単語ページの語源の欄は、直訳（または元の意味）・つまり・今の意味の3段で書いてあります。

語根の覚え方

語根は、知っている語とセットにしておくと、意味を思い出すときの手がかりになります。次の順で進めてください。

  1. 表の20個を、意味だけ先に覚える。fac＝作る、spect＝見る、のように1語で言えれば十分です。
  2. 1つの語根につき、よく知っている語を1つ決める。spect なら expect、ten なら contain のように、表の「おもな語」から選びます。語根の意味を忘れたら、その語から思い出せます。
  3. 新しい語は、知っている語と並べて覚える。perspective を覚えるときは「expect と同じ spect、per（通して）見る → 見通す → 観点」とつなげます。maintain なら contain と同じ tain（保つ）です。
  4. まぎらわしい組は、ちがう部品だけを見る。propose と oppose なら pro と op、attract と distract なら at と dis です。

長文で知らない語に会ったときも、語根は手がかりになります。たとえば retain を知らなくても、re（後ろに）＋ tain（保つ）から「手放さずに持っておく」と見当がつきます。

例：The town has retained much of its old charm.（その町は昔ながらの魅力の多くを保っている）

ただし、上の apply と supply のような例もあるので、見当をつけたら前後の文で確かめてください。structure（積み上げたもの → 構造）のように、語根の意味が今の意味に近い語から始めると、語根で読む練習になります。

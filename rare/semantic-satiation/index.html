semantic satiation

/sɪˈmæntɪk ˌseɪʃiˈeɪʃn/スィマンティック・セイシエイション
  1. 1名詞意味飽和

本や記事でときどき見る語。心理学の用語。数えない名詞

semantic satiation（意味飽和）は、同じ言葉をくり返し言ったり、じっと見つめたりするうちに、その意味が一時的にぼやけ、ただの音や文字の集まりのように感じられる現象を指す心理学の用語です。数えない名詞です。

たとえば、忘れないように「たまご」と唱えながら店まで歩くうちに「た・ま・ご」という音にしか聞こえなくなり、売り場で卵を見ると意味が戻る、といった体験がこれにあたります。1919年のアメリカの実験でも、cat のような短い名詞を声に出してくり返させています。

日本ではこの体験も「ゲシュタルト崩壊」と呼ばれることがよくあります。ただし、ゲシュタルト崩壊はもともと、字や形のまとまりがくずれて見えることを指す言葉です。英語では、意味のほうが抜ける体験を semantic satiation という別の名前で呼んでいます。

使われ方

semantic satiation は心理学の専門用語で、英語を話す人どうしの雑談ではあまり使われません。使われるのは、心理学の論文や、ことばや脳について一般向けに紹介する文章の中です。

会話では、It doesn't even sound like a word anymore.（もう言葉に聞こえない）や The word stopped making sense.（その言葉、意味が分からなくなってきた）のような言い方のほうがよく使われます。

発音は、同じ語源の satisfy が「サ」で始まるのに対し、satiation は「セイ」で始まります。

心理学の専門用語で、Cambridge や Merriam-Webster などの一般的な英語辞書には、見出し語としてのっていません。後半の satiation だけでも、かたい言葉（formal）の印がついています。

語源

  • semant　しるし（ギリシャ語）
  • ic　〜の（形容詞の語尾）
  • sati　十分・満腹（ラテン語）
  • ation　〜すること（名詞の語尾）

同じ「しるし」から：semaphore（手旗信号）

同じ「満たす」の根から：satisfy（満足させる）、asset（財産）、satire（風刺）、sad（悲しい）

2語の名前で、前半はギリシャ語、後半はラテン語から来た部品です。

前半の semantic は「意味の」という形容詞で、さかのぼるとギリシャ語の「しるし」に行きつきます。そこから「しるしで示す」、さらに「意味をもつ」という意味が生まれました。

後半の satiation は satiate（いやになるほど満腹にさせる）の名詞形で、ラテン語の satis（十分）から来た satiare（いっぱいに満たす）がもとです。satisfy も、satis に facere（作る）を合わせた「十分にする」が出発点です。

同じ「満たす」の根からは sad（悲しい）も生まれています。古い英語の sæd は「おなかいっぱいの、うんざりした」という意味で、そこから「疲れた」、さらに「悲しい」へと意味が移りました。ドイツ語で「満腹の」を表す satt も同じ仲間で、こちらは今も「満腹」の意味で使われています。

asset（財産）も同じ根から来ています。もとは古いフランス語の asez（十分に）で、亡くなった人の借金を払うのに足りるだけの財産を指していました。風刺の satire も、ラテン語の satur（満腹の）から来た「果物の盛り合わせの皿」がもとだとされています。

部品どおりに読むと「意味の満腹」で、同じ言葉をくり返すうちに、その意味がそれ以上感じられなくなる状態を表しています。

1907年、アメリカの心理学者 Elizabeth Severance と Margaret Floy Washburn は、印刷された1つの単語を3分間見つめ続けてもらう実験を発表しました。blood や career のような見なれた語が、見なれない外国の言葉のように見えはじめ、ただの文字の集まりになっていくようすが記録されています。

1919年には Bassett と Warne が、cat や box のような1音節の名詞を声に出してくり返させ、意味が抜け落ちていくようすを調べました。この現象には長いあいだ決まった名前がなく、研究者によって inhibition（おさえこみ）、mental fatigue（心の疲れ）、lapse of meaning（意味の抜け落ち）、verbal satiation（言葉の飽和）などと呼ばれていました。

semantic satiation という名前が論文の題名に出てくるのは、確認できる中では1961年、2つの言葉を話す人（bilinguals）を調べた Jakobovits と Lambert の論文が最初です。

字の形がくずれて見えるほうの体験は、日本では1910年に小説に書かれています。夏目漱石が朝日新聞に連載した『門』の最初の章で、主人公の宗助は、紙に書いた「今」の字をながめていると「見れば見るほど今らしくなくなって来る」と妻に話し、妻は「まさか」と答えます。

ゲシュタルト崩壊という名前は、ドイツ語の Gestaltzerfall（形のまとまりの崩れ）から来ています。1947年に Faust がドイツの医学雑誌 Der Nervenarzt でこれを論じたときは、銃弾で脳の両側をけがした人の症状として扱われていました。けがのない人にも起こると知られるようになったのは、そのあとです。漱石の小説は、この論文より37年前に書かれています。

2024年には、コンピューター上の神経回路のモデルでこの現象を再現した研究が発表されました。ただ、その論文でも、意味が抜ける仕組みはまだ分かっていないとされています。1907年の最初の実験から100年あまりたった今も、仕組みははっきりしていません。

例文

  • I kept repeating "eggs" all the way to the store so I wouldn't forget, and now semantic satiation has kicked in.

    忘れないように店まで「卵、卵」と唱え続けていたら、だんだん意味がぼやけてきた。

  • Stop saying "spoon" over and over! You're giving me semantic satiation.

    「スプーン」って何回も言うのはやめて。意味が分からなくなってきた。

関連する語

  • semantic　「意味の」という形容詞です。
  • satisfy　満足させる。satiation と同じく、ラテン語の satis（十分）から来ています。
  • asset　財産。もとは「十分に」という意味で、satiation と同じ satis の仲間です。
  • mondegreen　歌詞などを聞きまちがえる現象を表す語です。音から意味が抜けるのではなく、音に別の意味がついてしまう現象です。

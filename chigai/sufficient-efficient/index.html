sufficient と efficient の違い

sufficient は「十分な」、efficient は「効率的な・有能な」です。

sufficient

/səfɪ́ʃənt/サフィシェント

入試127本

  • 形容詞十分な

efficient

/əfɪ́ʃənt/イフィシェント

入試157本

  • 形容詞効率的な入試で最多
  • 形容詞有能な、手際のよい

見分けるポイント

  1. sufficient は量が足りていること。enough とほぼ同じ意味で、よりかたい語。
  2. sufficient for ～／sufficient to do「～に（…するのに）十分な」。反対語は insufficient。
  3. efficient は無駄なく働くこと。energy-efficient「省エネの」。人に使うと「手際のよい」。

例文で比べる

同じ場面で使い分けると、こうなります。

  • sufficient

    We have sufficient time to finish the project.

    その課題を終わらせる時間は十分にある。
  • efficient

    We need a more efficient way to finish the project.

    その課題を終わらせるもっと効率的な方法が必要だ。

アプリの例文

  • sufficient形容詞十分な

    We don't have sufficient time to finish the project.そのプロジェクトを終えるのに十分な時間がない。

  • efficient形容詞効率的な

    This new heater is more efficient than the old one.この新しいヒーターは古いものより効率がよい。

確認問題

入るほうをタップ。

  1. This new car is more 　　　（空所） in its use of fuel.

    答えを見る

    正解efficient燃料の使い方に無駄がない＝効率的。

  2. There is not 　　　（空所） evidence to prove that he is guilty.

    答えを見る

    正解sufficient有罪を証明するには証拠の「量が足りない」。

  3. Is two hundred dollars 　　　（空所） for a week's trip?

    答えを見る

    正解sufficientsufficient for ～「～に十分な」。金額の量。

  4. She is a very 　　　（空所） secretary who never wastes time.

    答えを見る

    正解efficient時間を無駄にしない「有能な、手際のよい」。

入試ではどっちが多い？

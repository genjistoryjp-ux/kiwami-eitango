英単語の派生語は覚えるべき？入試に多い派生語と覚え方

2026年10月30日

見出し語だけ覚えて、派生語は後回しにしていませんか。入試の英文で数えると、見出し語より派生語のほうが多くの試験に出ている語が少なくありません。

この記事のポイント
  • different は differ の約7倍。見出し語より派生語がよく出る語もある
  • 語尾で品詞の見当はつく。ただし​-⁠al・​-⁠ive・​-⁠en は例外に注意
  • 品詞のちがう形を1組にして、アクセントとつづりの変化も確かめる

結論から言うと、英単語の派生語は後回しにせず、見出し語といっしょに覚えるのがおすすめです。入試の英文では、見出し語より派生語のほうがよく出てくる語が少なくないからです。

  • differ（異なる）：172本 → 形容詞の different：1,162本
  • profession（職業）：68本 → professional（プロの、専門的な）：267本
  • commerce（商業）：27本 → commercial（商業の）：148本

国公立・私立の大学入試（2020〜2026年度）の英語1,588本で、見出し語と派生語の出かたを比べた結果です。後半では、語尾から品詞を見分ける方法、否定の接頭辞、アクセントの注意点、派生語の覚え方を説明します。

1本は試験問題1回分のことです。本数は、その語（​-⁠s、​-⁠ed、​-⁠ing などの形もふくむ）が1回でも出てきた試験の数です。

見出し語より派生語のほうが多く出る語

このサイトの受験英単語では、多くの見出し語に派生語をのせています。そのうち、見出し語に語尾や接頭辞を足してできた派生語の組が1,595組（見出し語1,242語）ありました。

この1,595組について、見出し語と派生語がそれぞれ何本の試験に出たかを比べると、次のようになりました。

  • 派生語のほうが多くの試験に出ていた組：84組
  • 派生語が100本以上の試験に出ていた組：89組

おもな組を、派生語の本数が多い順に並べました。

「派生語だけが出た本数」は、派生語は出てきたのに、見出し語は1回も出てこなかった試験の数です。派生語そのものが受験英単語の見出し語になっている組（respond と responsible など）は除きました。remaining や satisfied のように、動詞の ​-⁠ed・​-⁠ing の形と見分けられない派生語も除いています。

つまり、表の語は、見出し語よりも派生語のほうに入試で出会うことが多いということです。

見出し語が出ない試験にも、派生語は出る

281本response が出た393本のうち、respond が一度も出てこなかった試験

respond しか覚えていなければ、その281本では response の意味を語尾から推測するしかありません。

different も、1,162本のうち1,018本が differ の出てこない試験です。organization と organize、professional と profession の組も同じで、見出し語が出ずに派生語だけが出る試験がたくさんあります。

見出し語の何倍も出る派生語

6.8倍different が出た試験の数は、differ の6.8倍

差の大きさで見ると、ほかにも見出し語の何倍も出ている派生語があります。

  • simultaneous（同時の）は15本なのに、副詞の simultaneously は69本で4.6倍
  • commercial は commerce の5.5倍
  • professional と executive も、見出し語の3倍以上

見出し語は、その仲間の中でいちばんよく出る形とは限らないのです。

executive は、execute（実行する）から「重役」という意味を思いつくのは難しいので、派生語として別に覚えておきたい語です。

どの派生語もよく出るわけではない

ただし、派生語がどれもよく出るわけではありません。1,595組を見ると、次のとおりです。

  • 派生語の本数が見出し語の半分以上あった組：301組（全体の5分の1ほど）
  • 派生語が入試に一度も出なかった組：62組

派生語を全部同じ重さで覚える必要はありません。表のようによく出る形から先に押さえれば十分です。

語尾を見れば品詞の見当がつく

派生語の多くは、見出し語に決まった語尾をつけてできています。語尾には品詞を決める働きがあるので、知らない語でも、名詞か形容詞かといった見当がつきます。

入試の英文に、それぞれの語尾で終わる語が何種類出てきたかを数えました。

5文字以上の語を、​-⁠s・​-⁠ed・​-⁠ing などの形と合わせて1語として数えました。人名や地名のように大文字で書かれることが多い語は除いています。「目安どおりの割合」は、このうちこのサイトの単語データに品詞がのっている語で、目安の品詞として使われる語の割合です。

つまり、​-⁠tion・​-⁠ment・​-⁠ity・​-⁠ness・​-⁠ous・​-⁠ful・​-⁠ize は、ほぼ目安どおりと考えてかまいません。​-⁠ly・​-⁠al・​-⁠ive・​-⁠less には例外があり、​-⁠en は半分以下しか当たりません。

名詞の語尾：​-⁠tion・​-⁠ment・​-⁠ity・​-⁠ness

名詞の4つの語尾は、ほとんど例外がありません。​-⁠tion で終わる語は970種類と、名詞の語尾の中でいちばん多く出てきました。

  • ​-⁠tion：動詞につくと「～すること」という名詞になる（educate → education、produce → production）
  • ​-⁠ment：動詞から名詞を作る（develop → development、move → movement）
  • ​-⁠ity・​-⁠ness：形容詞から名詞を作る（diverse → diversity、aware → awareness）

ただ、mention（～に言及する）や question（～に疑問をもつ）のように、​-⁠tion で終わっていても同じ形のまま動詞として使う語はあります。

形容詞の語尾：​-⁠al・​-⁠ive・​-⁠ous・​-⁠ful・​-⁠less

​-⁠ous と ​-⁠ful は、ほぼ形容詞と考えてかまいません。気をつけたいのは、目安どおりの割合が8割ほどの ​-⁠al と ​-⁠ive です。

​-⁠al は、動詞のあとにつくと名詞になることが多い語尾です。

  • arrive → arrival（到着）、survive → survival（生存）
  • propose → proposal（提案）、approve → approval（承認）

animal、hospital、festival も名詞ですし、reveal（～を明らかにする）は動詞です。

​-⁠ive にも、receive、arrive、survive、perceive のような動詞や、perspective（観点）、initiative（主導権、新しい取り組み）、incentive（動機づけ、報奨）のような名詞が混ざっています。

形容詞の ​-⁠ive の多くは、create → creative、act → active、expense → expensive のように、動詞や名詞に足した形です。receive や arrive は、​-⁠ive を取ると単語になりません。

​-⁠less は名詞について「～のない」という意味の形容詞を作ります（use → useless、home → homeless）。​-⁠less と ​-⁠ful には、まぎらわしい語もあります。

  • countless：「数がない」ではなく「数えきれないほど多い」
  • regardless：副詞（regardless of ～：～に関係なく）
  • unless：接続詞（～しない限り）
  • handful：​-⁠ful で終わるが名詞。a handful of ～ で「ひと握りの～、少数の～」

regardless と unless は、どちらも入試によく出ます。

副詞の語尾：​-⁠ly

​-⁠ly で終わる語は1,401種類で、表の中でいちばん種類の多い語尾でした。形容詞に ​-⁠ly がつくと副詞になります（actual → actually、recent → recently）。

ただし、名詞に ​-⁠ly がつくと形容詞になります。friendly（親しみのある）、lovely（すてきな）、costly（費用のかかる）がその例です。

friendly は副詞ではないので、She spoke to me friendly. とは言えず、She spoke to me in a friendly way. のように言います。family、supply、apply、reply も ​-⁠ly で終わりますが、副詞ではありません。

動詞の語尾：​-⁠ize・​-⁠en

​-⁠ize は名詞や形容詞を動詞にする語尾で、目安どおりの割合は99%でした（real → realize、symbol → symbolize）。イギリス式のつづりでは realise のように ​-⁠ise と書くこともあります。

47%​-⁠en で終わる語のうち、目安どおり動詞として使われる語の割合

いちばん当てにならないのが ​-⁠en です。形容詞や名詞を動詞にする働きは、たしかにあります。

  • weak → weaken（弱める）、short → shorten（短くする）
  • threat → threaten（おびやかす）、strength → strengthen（強化する）

入試でも threaten は287回、strengthen は142回、weaken は106回出てきました。

それでも、​-⁠en で終わる語の多くは、children、women、often、between のような語や、given、taken のような動詞の変化形で、目安どおりの割合は半分以下です。wood → wooden、gold → golden のように「～でできた」という形容詞を作ることもあります。

​-⁠en は、語尾だけで品詞を決めないほうがよい語尾です。

否定の接頭辞 un-・in-・im-・dis-

語の頭について、意味を反対にする接頭辞もあります。こちらは品詞を変えません。

  • un-：likely → unlikely（ありそうもない）、pleasant → unpleasant（不愉快な）
  • in-：visible → invisible（目に見えない）、consistent → inconsistent（矛盾した）
  • im-（p・b・m の前）：possible → impossible、patient → impatient（いらいらした）、moral → immoral（不道徳な）
  • il-（l の前）・ir-（r の前）：legal → illegal、regular → irregular、relevant → irrelevant
  • dis-：agree → disagree、appear → disappear、approve → disapprove

im-、il-、ir- は、in- のつづりが次の文字に合わせて変わったものです。

否定の形もよく出ます。unlikely は151本、invisible は65本、irregular は45本の試験に出ていました。

「～でない」と訳すとまちがえる語

  • invaluable は「価値がない」ではなく「非常に貴重な」。入試では14本に出ていました。「価値がない」は worthless です。priceless も「値段がつけられないほど貴重な」という意味です。
  • infamous は「有名でない」ではなく「悪名高い」。
  • indifferent は「違いがない」ではなく「無関心な」（be indifferent to ～）。

否定ではない un-・in-・im-

  • uncover（～を暴く）、unfold（～を広げる、展開する）、unload（荷を降ろす）の un- は、否定ではなく「逆の動作」です。
  • imprison（～を投獄する）の im- は「中へ」の意味です。
  • income（収入）の in- も否定ではありません。

品詞が変わるとアクセントが動く語

派生語では、強く読む位置が変わることがあります。​-⁠tion、​-⁠ic、​-⁠ical、​-⁠ity がつくと、そのすぐ前の音節を強く読むのが基本です。

つまり、表のどの組も、派生語になると強く読む位置が後ろにずれています。

origin → original や photograph → photographer のように、ほかの語尾でもアクセントが動く語があります。反対に、politics は ​-⁠ics で終わるのに最初の pol を強く読む例外です。

一方、​-⁠ness、​-⁠ment、​-⁠ful、​-⁠less、​-⁠ly は、ふつうアクセントを動かしません（happy → happiness、develop → development）。

発音やアクセントを問う問題を出す大学もありますし、リスニングでは、強く読む位置がちがうと同じ仲間の語だと気づきにくくなります。

派生語を覚えるときは、音声で強く読む位置も確かめておきましょう。

派生語の覚え方

見出し語と、品詞を変えた形を1組で覚える

respond（動詞）と response（名詞）のように、品詞のちがう形を1組にして覚えます。形が似ているので、別々の日に別の単語として覚えるより、いっしょに覚えたほうが負担は小さくなります。

そのとき、よく使う形もいっしょに口に出しておくと、英作文でも使えるようになります。

  • respond to ～（～に反応する）
  • in response to ～（～に応えて）

例文の中で品詞を確かめる

品詞は、文の中の位置で確かめるのが確実です。

  • a や the で始まるまとまりの最後にある → 名詞
  • 名詞の前や be 動詞のあとにある → 形容詞
  • 動詞や文全体を説明している → 副詞

たとえば She works for a large organization. の organization は、a large のあとにあるので名詞です。The two events happened simultaneously. の simultaneously は、動詞 happened を説明しているので副詞です。

知らない派生語は語尾から推測する

見出し語を知っていれば、初めて見る派生語も語尾から意味を推測できます。The city has strengthened its rules. なら、strength（強さ）に ​-⁠en がついた動詞なので「規則を強化した」と読めます。

語尾を足すのではなく、付けかえてできる派生語もあります。cognition（認知）の ​-⁠tion を ​-⁠ive にかえた cognitive（認知の）は、cognition の50本よりずっと多い188本に出ていました。

executive（重役）のように推測しにくい意味になる語もあります。推測は「当たりをつける」くらいにとどめ、確かめてから覚えましょう。

つづりが変わる派生語に注意する

次の組は、読むときはわかっても、書くときにまちがえやすい組です。

  • pronounce → pronunciation
  • explain → explanation
  • curious → curiosity
  • decide → decision
  • maintain → maintenance

まとめ

  • 見出し語より派生語のほうが多くの入試に出る語がある（different は differ の約7倍、response は393本のうち281本が respond の出ない試験）
  • ただし、どの派生語もよく出るわけではないので、よく出る形から先に押さえる
  • 語尾で品詞の見当はつくが、​-⁠al・​-⁠ive は8割ほど、​-⁠en は半分以下しか目安どおりにならない
  • invaluable（非常に貴重な）のように「～でない」と訳すとまちがえる語や、アクセント・つづりが変わる派生語に注意する
  • 覚えるときは、品詞のちがう形を1組にして、例文と音声で確かめる

# 極（きわみ）

受験・TOEIC の英単語を、複数の意味・派生語・AI 音声で覚える Web アプリです。

- 4択でサクサク解き、答えた速さと正誤から次の復習日を自動で決めます（間隔反復）
- 意味は1つずつ、派生語も見出し語のあとに出題します
- スマホのホーム画面に追加でき、オフラインでも動きます

**使う：** https://genjistoryjp-ux.github.io/kyokutan/

学習記録はその端末のブラウザに保存されます（ログインした場合はアカウントに保存）。
単語データ・例文はこのアプリのために独自に作成したものです。発音は Kokoro（Apache-2.0）で生成しています。

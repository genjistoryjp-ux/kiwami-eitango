「〜に向かって・逆らって」の接頭語

ob- / oc- / of- / op- の意味

動詞や名詞の前に付いて「〜に向かって」「〜に逆らって」の意味を加えます。

意味
〜に向かって・逆らって
形
ob- oc- of- op-
  • c の前で oc-、f の前で of-、p の前で op- になります。occur, offer, oppose。
  • oppose（反対する）、object（反対する）、obstacle（障害）は「逆らって」の意味です。
  • observe（観察する）、obtain（手に入れる）、obey（従う）は「〜に向かって」の意味です。
  • opportunity は「港（port）に向かう風」から「好機」の意味になった語です。

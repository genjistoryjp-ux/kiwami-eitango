動詞を作る接尾語

-ize / -ise の意味

名詞や形容詞のうしろに付いて動詞を作ります。「〜にする」「〜化する」を表します。

意味
〜にする・〜化する
品詞
動詞を作る
形
-ize -ise
  • real → realize、modern → modernize、custom → customize。
  • イギリス式では -ise とつづります。realise, organise。
  • 名詞にすると -ization になります。organize → organization、realize → realization。
  • critic → criticize、emphasis → emphasize のように元の語の形が少し変わる語もあります。

-ize / -ise が付いてできる単語26語

左が元の単語、右が接尾語の付いた単語です。

  • social→socialize交際する、付き合う
  • character→characterize～を特徴づける
  • personal→personalize～を個人向けにする、（個人に）合わせる
  • familiar→familiarize～に慣れる、～をよく知る
  • global→globalize～を世界規模にする、グローバル化する
  • custom→customizeカスタマイズする、特注する
  • modern→modernize～を近代化する
  • normal→normalize正常化する；当たり前のことにする
  • public→publicize～を公表する、宣伝する
  • standard→standardize～を標準化する、規格化する
  • legal→legalize～を合法化する
  • industrial→industrialize～を工業化する
  • revolution→revolutionize～に大変革をもたらす
  • material→materialize実現する、具体化する；（突然）現れる
  • capital→capitalize～を利用する、～につけ込む
  • internal→internalize～を内面化する、身につける
  • rational→rationalize～を正当化する、合理化する
  • neutral→neutralize中和する、無力化する
  • fossil→fossilize化石化する；（考えなどが）硬直化する
  • marginal→marginalize～を社会の隅に追いやる
  • trivial→trivialize～を矮小化する、軽視する
  • sterile→sterilize～を殺菌する、消毒する
  • general→generalize一般化する、概括する
  • visual→visualize～を思い描く
  • democrat→democratize～を民主化する；～を（誰でも利用できるよう）大衆化する
  • commercial→commercialize～を商業化する

語源に -ize をもつ単語16語

下線が接尾語の部分です。単語を選ぶと語源の説明が見られます。

  • realize～に気づく、～を悟る
  • recognize～だとわかる、見分ける
  • organize～を企画する、準備する
  • apologize謝罪する
  • criticize～を批判する、非難する
  • emphasize～を強調する、重視する
  • specialize～を専門にする、専攻する
  • summarize～を要約する、まとめる
  • utilize～を利用する、活用する
  • advertise～を宣伝する、広告する
  • minimize～を最小限にする
  • symbolize～を象徴する、表す
  • jeopardize～を危険にさらす
  • mobilize～を動員する、結集する
  • globalizationグローバル化、国際化
  • scrutinize～を詳しく調べる、精査する

semantic satiation

スィマンティック・セイシエイション/sɪˈmæntɪk ˌseɪʃiˈeɪʃn/名詞

何度も言った言葉が、急にただの音に聞こえたこと、ある？

この単語の、ここが変

  1. 1sad（悲しい）は、もとは「おなかいっぱい」という意味だった語源
  2. 2ドイツで「ゲシュタルト崩壊」が論じられる37年前に、漱石が小説に書いていたこの言葉の歩み
  3. 3「ゲシュタルト崩壊」と呼ばれがちな、意味がぬけるあの感じ。英語では別の名前どんなときの言葉？

ひとことで言うと

意味飽和

同じ言葉をくり返したり見つめたりするうちに、その意味が一時的にぼやけてしまう現象のことです。

見かける度：まれ/数えない名詞/心理学の用語/1つの辞書にのっている

01どんなときの言葉？

その「たまごって何？」に、英語の名前がある

忘れないように、スーパーまでの道で「たまご、たまご、たまご」と唱えながら歩く。店に着くころには、口から出ているのは、もう「た・ま・ご」という音だけです。

たまご、たまご……たまごって、何？

卵の売り場を見たとたん、ちゃんと「たまご」に戻る。この、くり返すうちに言葉の意味がふっと抜け落ちる現象が semantic satiation です。日本語では「意味飽和」と呼ばれます。

ためしに今、「ねこ」を声に出して30回言ってみてください。20回をこえたころから、ふわふわの動物の姿が遠のいて、「ね」と「こ」という2つの音がころがっているだけに聞こえてきませんか。1919年のアメリカの実験でも、くり返す言葉に選ばれたのは cat のような短い名詞でした。

日本では、この体験も「ゲシュタルト崩壊」と呼ばれることがよくあります。ただ、ゲシュタルト崩壊はもともと、字や形のまとまりがくずれて見えることを指す言葉です。英語では、意味のほうがぬける体験に、別の名前をつけています。

semantic satiation
「意味」がうすれる。声に出しても、見つめても起こる。
ゲシュタルト崩壊
「形のまとまり」がくずれる。漢字のへんとつくりが、ばらばらの線に見える。
orthographic satiation
漢字のゲシュタルト崩壊を、英語の研究ではこう呼ぶことがある。

02で、どこで使うの？

論文の言葉。会話ではこう言う

semantic satiation は心理学の専門用語なので、英語を話す人どうしの雑談ではあまり出てきません。見かけるのは、心理学の論文や、ことばや脳のふしぎを紹介する読み物の中です。

会話なら、It doesn't even sound like a word anymore.（もう言葉に聞こえない）や The word stopped making sense.（その言葉、意味が分からなくなってきた）のように言う人のほうが多いでしょう。

親せきの satisfy は「サ」なのに、satiation は「セイ」と読みます。

03語源

名前の意味は、「意味の満腹」

前半の semantic は「意味の」という形容詞で、もとをたどるとギリシャ語の「しるし」です。そこから「しるしで示す」、さらに「意味をもつ」と意味が育ちました。

後半の satiation は satiate（いやになるほど満腹にさせる）の名詞形で、ラテン語の satis（十分）から来た satiare（いっぱいに満たす）がもとです。おなじみの satisfy も、satis に facere（作る）をつけた「十分にする」が出発点です。

この「満たす」の根っこには、いちばん意外な親せきがいます。sad（悲しい）です。古い英語の sæd は「おなかいっぱいの、もううんざりの」という意味でした。そこから「疲れた」、そして「悲しい」へと意味が移っていきました。

ドイツ語では

satt満腹の

ドイツ語で「おなかいっぱいの」は satt。sad と同じ根から来た仲間です。英語の sad は「悲しい」まで遠くへ行きましたが、ドイツ語のほうは今も「満腹」のままです。

同じ根っこからは、asset（財産）も育っています。もとは古いフランス語の asez（十分に）。もともとは、亡くなった人の借金を払うのに「足りる」だけの財産を指していました。風刺の satire も、ラテン語の satur（満腹の）から来た「果物を盛り合わせた皿」がもとだとされています。

部品どおりに読むなら、同じ言葉を何度も口に入れるうちに、頭がおなかいっぱいになって、もう味がしなくなる。

04この言葉の歩み

今の名前に落ち着くまで、半世紀あまり

  1. 1907Severance と Washburn が、単語を3分間見つめる実験を発表
  2. 1910夏目漱石が『門』で、「今」の字が今らしく見えなくなる場面を書く
  3. 1919Bassett と Warne が、cat などを声でくり返す実験をする
  4. 1947Faust がドイツの医学雑誌で Gestaltzerfall を論じる
  5. 1961semantic satiation の名前が、論文の題名に出る
  6. 2024コンピューター上のモデルで、この現象を再現する研究が出る

1907年、アメリカの心理学者 Elizabeth Severance と Margaret Floy Washburn は、印刷された1つの単語を3分間見つめ続けてもらう実験をしました。blood や career のような見なれた語が、見なれない外国の言葉のような顔つきに変わり、ただの文字の集まりになっていくようすが記録されています。

最初にふれた cat の実験は、1919年の Bassett と Warne によるものです。cat や box のような短い名詞を声に出してくり返させて、意味が抜け落ちていくようすを調べました。それでも、この現象には長いあいだ決まった名前がありませんでした。semantic satiation という名前が論文の題名に出てくるのは、確かめられる中では1961年、2つの言葉を話す人（bilinguals）を調べた論文が最初です。

前の呼び名

lapse抜け落ち of meaning

決まった名前がなかったころ、この現象は inhibition（おさえこみ）、mental fatigue（心の疲れ）、lapse of meaning（意味の抜け落ち）、verbal satiation（言葉の飽和）など、研究者ごとにばらばらの名前で呼ばれていました。

いっぽう、字の形がくずれて見えるほうの体験は、日本では1910年にもう小説に書かれていました。夏目漱石が朝日新聞に連載した『門』の最初の章で、主人公の宗助は、紙に書いた「今」の字をながめていると「見れば見るほど今らしくなくなって来る」と妻に打ち明け、「まさか」と本気にしてもらえません。

ゲシュタルト崩壊という名前は、ドイツ語の Gestaltzerfall（形のまとまりの崩れ）から来ています。

ゲシュタルト崩壊は、頭を撃たれた人の症状として論じられた言葉でした。

1947年、ドイツの医学雑誌 Der Nervenarzt にのった、Faust の論文です。

1947年に Faust がドイツの医学雑誌でこれを論じたとき、扱ったのは、銃弾で脳の両側をけがした人の症状でした。けがのない人にも起こると知られるのは、そのあとのことです。漱石の小説は、その論文より37年も早かったことになります。

なぜ意味が抜けるのか。2024年にはコンピューター上のモデルで再現した研究も出ましたが、仕組みは100年あまりたった今も、はっきりしていません。次にスーパーへの道で「たまご」がただの音に聞こえたら、それは研究者たちがまだ解けていない、小さななぞです。

05例文

言いすぎて、意味がぼやけたら

I kept repeating "eggs" all the way to the store so I wouldn't forget, and now semantic satiation has kicked in.

忘れないように店まで「卵、卵」と唱え続けていたら、だんだん意味がぼやけてきた。

Stop saying "spoon" over and over! You're giving me semantic satiation.

「スプーン」って何回も言うのやめて！意味が分からなくなってきたよ。

06似た言葉・あわせて見る

部品が同じ単語と、逆の現象

  • semantic意味の。ことばの話によく出てくる形容詞です
  • satisfy満足させる。satiation と同じく、ラテン語の satis（十分）から来ています
  • asset財産。もとは「十分に」という意味で、satiation と同じ satis の仲間です
  • mondegreen珍しい単語歌詞を聞きまちがえる現象。意味が抜けるのとは逆に、音にちがう意味がついてしまう語です

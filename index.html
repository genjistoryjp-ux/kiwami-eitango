このサイトについて

極（きわみ）は、共通テストと大学入試の英語の問題を数えて、英単語がどのくらい出たか、どの意味で使われたかをまとめたサイトです。数えたのは、令和6〜8年度の共通テスト英語12本と、国公立・私立157校の大学入試英語1,588本です。

受験英単語3,467語には、1語ずつページがあります。意味と例文のほかに、その単語が何本の試験に出たか、入試の英文ではどの意味で使われることが多いかを載せています。

大学受験のために英単語を覚えている人に向けて作っています。調べたい単語は上の検索から引けます。覚え方や大学ごとの傾向は記事に、似ていてまぎらわしい単語は「違い」のページにまとめています。数字の数え方は数字の見方をどうぞ。

まぎらわしい英単語の違い

一覧を見る →
  • affect と effectaffect は「～に影響を与える」という動詞、effect は「影響・効果」という名詞です。
  • raise と riseraise は「～を上げる」という他動詞、rise は「上がる」という自動詞です。
  • borrow と lendborrow は「（人から）～を借りる」、lend は「（人に）～を貸す」です。
  • economic と economicaleconomic は「経済の」、economical は「節約になる・安上がりな」です。
  • effective と efficienteffective は「効果的な（よい結果が出る）」、efficient は「効率的な（無駄がない）」です。
  • lie と laylie は「横になる」という自動詞、lay は「～を横たえる・置く」という他動詞です。

思いこみの意味で読むと外す単語

  • present思いがち：プレゼント（贈り物）
    入試で多い～を提示する、発表する
  • manner思いがち：マナー（行儀、作法）
    入試で多い方法、やり方
  • claim思いがち：クレーム（苦情）
    入試で多い～と主張する
  • implication思いがち：暗示、含意
    入試で多い（予想される）影響、結果

「入試で多い」は、その単語の入試の文（1語につき最大180文）でいちばん多かった意味です。

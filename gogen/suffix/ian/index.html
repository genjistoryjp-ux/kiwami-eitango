名詞を作る接尾語

-ian / -an の意味

名詞や形容詞のうしろに付いて名詞を作ります。「〜の人」「〜の専門家」を表し、形容詞として使う語もあります。

意味
〜の人
品詞
名詞を作る
形
-ian -an
  • civil → civilian（民間人）、music → musician、pediatric → pediatrician（小児科医）。
  • 国名にも付きます。Italy → Italian、Canada → Canadian、America → American。
  • physician は「内科医」で、physicist（物理学者）とは別の語です。
  • pedestrian（歩行者）も -ian で「人」を表す語です。

-ian / -an が付いてできる単語2語

左が元の単語、右が接尾語の付いた単語です。

  • civil→civilian民間人
  • pediatric→pediatrician小児科医

語源に -ian をもつ単語6語

下線が接尾語の部分です。単語を選ぶと語源の説明が見られます。

  • ancient古代の、昔の
  • certainある、一定の
  • physician医者、（特に）内科医
  • urban都市の、都会の
  • veteranベテラン、経験豊富な人
  • pedestrian歩行者

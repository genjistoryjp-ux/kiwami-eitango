「間に・お互いに」の接頭語

inter- の意味

名詞・形容詞・動詞の前に付いて「間に」「お互いに」の意味を加えます。

意味
間に・お互いに
形
inter-
  • international（国と国の間の）、interpersonal（人と人の間の）、intercultural（異文化間の）。
  • interact（相互に作用する）、interrupt（間に割り込む）、interfere（干渉する）。
  • intelligent, intellectual の intel- も inter- の変化形です（間から選び取る→理解する）。
  • enterprise の enter- もフランス語を通った inter- です。

inter- が付いてできる単語4語

左が元の単語、右が接頭語の付いた単語です。

  • personal→interpersonal対人関係の、人間関係の
  • cultural→intercultural異文化間の
  • stellar→interstellar恒星間の
  • national→international国際的な

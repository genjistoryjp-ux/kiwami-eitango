共通テストと二次・私大で出る英単語のちがい｜入試データで比較

2026年10月30日

共通テストで目立つ英単語と、国公立の二次試験や私大で目立つ英単語は、顔ぶれがちがいます。入試の英文で数えた回数をもとに、そのちがいと覚える順番をまとめました。

この記事のポイント
  • 共通テストは案内・予定・メールの語が目立ち、outline は大学入試の約32倍
  • force や theory など論説文の語は、共通テストに0回でも二次・私大でよく出る
  • 二次・私大も受けるなら、論説文の語は夏までに手をつけておく
目次
  1. 共通テストで目立つ語（案内・予定・メール）
  2. 共通テストには出ない論説文の語
  3. 国立で多い語（医療・科学・心理）
  4. 私立で多い語（経済・社会・設問）
  5. 受ける試験に合わせた覚える順番
  6. まとめ

同じ受験英単語でも、共通テストでよく見る語と、二次試験や私大の問題でよく見る語は同じではありません。

  • 共通テスト：イベントの案内や予定、レビュー、メールのような、生活や実務の英語に出てくる語が目立つ
  • 二次・私大：研究や社会の問題を論じる文章の語が増え、共通テストに一度も出てこなかった語もある
  • 国立と私立：多く出る話題が少しずつちがう

この記事では、受験英単語4,104語が実際の入試の英文に何回出たかを、共通テストと大学入試（国立・公立・私立）で比べました。最後に、受ける試験に合わせた覚える順番を紹介します。

比べた英文：共通テストは令和6〜8年度の本試験・追試験で、リーディングとリスニングの読み上げ英文を別々に数えた12本です。大学入試は国公立・私立の大学入試（2020〜2026年度）で、国立566本、公立165本、私立857本の計1,588本です。

数え方：英文の量がちがうので、回数は「10万語あたり」にそろえました（3文字以上の語で数えて、共通テスト36,129語、国立933,040語、公立286,698語、私立1,584,484語）。変化形は見出しの語とまとめて数えています（predict なら predicts・predicted・predicting も含みます）。went のような不規則な形は含めていません。

共通テストで目立つ語（案内・予定・メール）

まず、共通テスト12本のうち5本以上に出た208語について、10万語あたりの回数が大学入試の何倍になるかを出し、大きい順に並べました。

約32倍1位の outline は、10万語あたり共通テスト72.0回、大学入試2.2回

共通テストは12本を合わせても、数えた語が約3.6万語と多くないので、register のように7回しか出ていない語も上位に入ります。

どんな場面で使う語か

並んだ語を見ると、共通テストにどんな英文が多いかが見えてきます。

  • 案内・お知らせ・予定の語：register（登録する、申し込む）、arrange（手配する）、schedule（予定）、event（行事、催し）、staff（職員）、local（地元の）。講座やイベントの案内、町のお知らせ、旅行の予定といった英文でおなじみです。
  • レビュー・投稿の語：comment、opinion
  • 選択肢の語：option。いくつかの案を比べて選ぶ場面でよく使われます。

表の下にも resident（住民）、activity、prepare、item（品物、項目）が続き、同じ傾向です。

設問を読む語、聞いてわかる語

共通テストのリーディングは設問や選択肢も英語で、事実（fact）と意見（opinion）を見分ける問いや、発表用のメモやアウトラインを完成させる問いもおなじみです。

outline、comment、opinion は、リーディング6本のすべてに出ていて、リスニングには出ていません。本文だけでなく、設問を読むための語としても押さえておきましょう。

一方、リスニングの読み上げ英文6本では、schedule が3本、event と local が4本に出ています。こうした語は、聞いてすぐ意味がわかるように音でも覚えておきたいところです。

二次・私大でも出る

共通テストで目立つ語が、二次・私大で出ないわけではありません。event は大学入試1,588本のうち496本、local は506本に出ています。共通テストのために覚えた語は、二次・私大でもそのまま役に立ちます。

共通テストには出ない論説文の語

反対に、共通テスト12本には一度も出なかったのに、大学入試ではよく出る語もあります。4,104語のうち、共通テストで0本、大学入試で150本以上という語は50語を超えます。

494本force は大学入試1,588本のうち494本、だいたい3本に1本の割合で出ているのに、共通テストでは1回も出ていない

共通テストで0本、大学入試で250本以上に出た主な語がこちらです。

共通テストは量が少ないので、たまたま出なかっただけの語もあるはずです。それでも、論説文の語がこれだけまとまって0本なのは、共通テストと二次・私大で英文の種類がちがうためと考えられます。

研究や社会を論じる文章の語

表の語は、研究や社会について筆者が意見を述べる論説文でよく使われます。

  • 研究を紹介する文章の定番：theory（理論）、predict（予測する）、structure（構造）、expert（専門家）、assume（仮定する）
  • 論説文らしい副詞：increasingly（ますます）は社会の変化や傾向を述べるとき、indeed（実際、それどころか）は前の内容を強めたり、さらに一歩進めたりするときに使われます。
  • 身近に見える動詞：force や fail も、論説文では be forced to do（〜せざるをえない）、fail to do（〜しない、〜できない）の形でよく使われます。

150〜249本の語も同じ傾向

150〜249本の語にも、論説文らしい語が並びます。

  • 論説文らしい語：intelligence（知能：239本）、context（背景、文脈：223本）、analysis（分析：218本）
  • 程度や範囲を表す副詞：largely（主に：209本）、significantly（著しく：199本）、necessarily（必ずしも：196本）、entirely（完全に：191本）

not necessarily（必ずしも〜とは限らない）や not entirely（完全に〜というわけではない）は部分否定です。内容一致や和訳で取りちがえやすいところなので、not と組み合わせた形で覚えておきましょう。

  • 社会や文化の語：immigrant（移民）、crime（犯罪）、religious（宗教の）、custom（慣習）、nuclear（核の、原子力の）

話題に関係なく使う語

一方、suitable（適した）、insist（主張する、言い張る）、nevertheless（それにもかかわらず）は、特定の話題の語ではありません。

  • nevertheless：前の内容から予想されることと逆の内容を続けて、論理の筋道をつくる語です。
  • insist：insist on 〜 や insist that 〜 の形で、人の主張や要求を紹介するときに使われます。
  • suitable：Choose the most suitable answer.（最も適切な答えを選べ）のように、英語で書かれた設問でもよく見かけます。

国立・私立の表を見るときの注意

表を見るときは、本数の列もあわせて見てください。vaccine は国立18本、私立21本で、出た本数の割合で比べると差はずっと小さくなります。1本の長文で同じ語がくり返し使われると、回数の差は大きく出ます。

また、差がいちばん大きい語でも3倍ほどで、片方にしか出ないわけではありません。bias は私立857本のうち46本に、profit は国立566本のうち29本に出ています。

志望校の種類で覚えない語を決めるのではなく、どちらを先に固めるかの目安にしてください。

受ける試験に合わせた覚える順番

ここまでの結果をもとに、覚える順番の目安をまとめます。どちらの場合も、土台になるのは試験の種類を問わず広く出る基本の語で、そこから先の広げ方が変わります。

共通テストが中心の人

  1. 大学入試全体でよく出る基本の語を先に固める。
  2. 共通テストで目立つ語を、案内やメールの英文の中で覚える。option、register、arrange、schedule などです。register for a course（講座に申し込む）、reply to an email（メールに返信する）、local residents（地元の住民）のように、場面でよく使う組み合わせごと覚えると、本番で読む速さが上がります。
  3. リスニングにも出る語は、音声で確認する。schedule や event などです。
  4. 余裕が出てきたら、論説文の語にも進む。theory、predict などです。長めの記事や説明文を落ち着いて読むための土台になります。

二次・私大まで受ける人

  1. 基本の語を固める。
  2. 夏までに、共通テストには出なかった論説文の語に手をつける。theory、assume、context、increasingly などです。秋以降は共通テスト形式の演習に時間を取られやすく、ここを後回しにすると、二次・私大の過去問に取りかかってから語彙の不足に気づいても、取り戻す時間があまり残っていません。
  3. 志望校に合わせて、話題の語を優先して足す。
    • 国立が中心なら：医療・科学・心理の語（virus、hypothesis、bias、evidence など）
    • 私立が中心なら：経済・社会の語（profit、purchase、competition など）と、設問でよく見る suitable、論理の筋道をつくる nevertheless
  4. 共通テストで目立つ語は、共通テストの過去問を解きながら仕上げる。具体的な場面で使う語が多いので、問題の中で出会うと覚えやすくなります。

単語は、実際の英文の中で何度も出会うことで定着していきます。どの順番で進める場合も、覚えた語を過去問や長文の中で見つけて、意味をすぐに思い出せるか確かめていきましょう。

まとめ

  • 共通テストは、案内・予定・メールのような生活の英文の語が目立つ。outline は10万語あたりで大学入試の約32倍。
  • outline、comment、opinion は、共通テストの設問を読むための語でもある。
  • force、theory、predict などの論説文の語は、共通テストに0本でも二次・私大でよく出る。
  • 国立は医療・科学・心理、私立は経済・社会の語が多めだが、差がいちばん大きい語でも3倍ほど。
  • 二次・私大も受けるなら、論説文の語は夏までに手をつける。

共通テストで何本に出たかの順位は共通テストに出た英単語ランキング、大学入試全体の順位は大学入試に出る英単語ランキング、4,104語すべては受験英単語一覧で見られます。表の単語をタップすると、その語の意味と例文、入試での出かたのページに移ります。

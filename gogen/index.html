接頭語・接尾語の一覧

英単語の多くは、前に付く部品（接頭語）と、うしろに付く部品（接尾語）で形が変わります。接尾語を見ると品詞がわかり、接頭語を見ると意味の向きがわかります。

接尾語接頭語

接尾語：うしろに付いて品詞を変える

たとえば protect に -tion が付くと protection（名詞）、modern に -ize が付くと modernize（動詞）になります。

名詞を作る

  • -tion / -ation / -sion〜することprotection
  • -ment〜すること・ものimprovement
  • -ness〜さ・〜であることawareness
  • -ity / -ty〜さ・〜性creativity
  • -ance / -ence / -ancy〜すること・〜であることappearance
  • -cy〜であることurgency
  • -ure / -ture〜すること・ものdeparture
  • -age〜すること・量・場所storage
  • -ship〜の関係・身分leadership
  • -hood〜の時期・状態adulthood
  • -ism〜主義racism
  • -er / -or〜する人・ものemployer
  • -ist〜する人・専門家scientist
  • -ian / -an〜の人politician
  • -ee〜される人employee
  • -ics / -logy〜学economics

形容詞を作る

  • -ous〜に満ちたcourageous
  • -ful〜に満ちたsuccessful
  • -less〜のないworthless
  • -able / -ible〜できるacceptable
  • -ive〜の性質をもつcreative
  • -al〜の・〜することcultural
  • -ic / -ical〜の・〜的なeconomic
  • -ary / -ory〜の・〜に関するrevolutionary
  • -ant / -ent〜している・〜する人dependent
  • -y〜の多い・〜することhealthy
  • -ed / -ing〜させられた・〜させるembarrassed

動詞を作る

  • -ize / -ise〜にする・〜化するmodernize
  • -ify / -fy〜にするsimplify
  • -en〜にする・〜になるweaken
  • -ate〜させる・〜にするoriginate

副詞を作る

  • -ly〜に・〜くcurrently

接頭語：前に付いて意味を足す

たとえば happy に un- が付くと unhappy（幸せでない）、view に re- が付くと review（見直す）になります。

否定

  • un-〜でない・逆にするunlikely
  • in- / im- / il-〜でないinconvenient
  • dis- / di- / dif-反対・〜でないdisagree
  • non-〜でない・非〜nonsense
  • mis-誤って・悪くmislead

向き・場所

  • in- / im- / en-中へ・中にenvironment
  • en- / em-〜にするenable
  • ex- / e- / ef-外へexport
  • re-再び・元へrecycle
  • de-下へ・離して・逆にdecrease
  • sub- / sup- / suc-下にsuburb
  • super- / sur-上に・越えてsupervisor
  • trans- / tra-向こうへ・越えてtradition
  • inter-間に・お互いにinternational
  • ad- / ac- / af-〜へ・〜にarrive
  • ob- / oc- / of-〜に向かって・逆らってopportunity
  • ab- / abs-離れてabsent
  • se-離して・分けてsecurity
  • per-通して・すっかりpermit

時・順番

  • pre-前に・前もってprehistory
  • pro- / pur- / por-前へ・前にpurpose

いっしょ・反対

  • con- / com- / col-共に・すっかりcooperate
  • syn- / sym-共に・同時にsystem
  • contra- / counter-反対に・逆らってcontrol

程度

  • over-越えて・〜しすぎるoverestimate
  • under-下に・足りないunderestimate

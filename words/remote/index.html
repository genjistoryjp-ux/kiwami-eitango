remote の語源

re離れてmote動かすmotor の mot

  1. 直訳

    離れたところへ動かされた

  2. つまり

    遠ざけられて遠くにある

  3. 今の意味

    遠く離れた・遠隔の

同じ「動かす」（mot / mov）の仲間
  • promote昇進させる前へ動かす
  • emotion感情心を外へ動かすもの
  • remove取り除くよそへ動かす

部品の解説re-接頭語

くわしく

ラテン語 remotus（遠ざけられた）から。removere（遠ざける）の過去分詞で、re（後ろへ・離れて）＋ movere（動かす）。

意味と例文

  1. 形容詞遠く離れた、へんぴな入試で48%

    They live in a remote village in the mountains.彼らは山奥のへんぴな村に住んでいる。

  2. 形容詞遠隔の、リモートの入試で最多 52%

    Remote work has become common in many companies.多くの会社でリモートワークが一般的になった。

  3. 形容詞（可能性が）わずかな

    There is only a remote chance of rain today.今日雨が降る可能性はごくわずかだ。

    現実から遠い → わずかな

日本語の「リモート」は、この remote のこと（英語の発音は「リモウト」に近い）。

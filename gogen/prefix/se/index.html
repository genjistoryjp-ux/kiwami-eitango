「離して・分けて」の接頭語

se- の意味

動詞や形容詞の前に付いて「離して」「別にして」の意味を加えます。

意味
離して・分けて
形
se-
  • separate（分ける）、select（選び出す）、segregate（隔離する）。
  • secure は se + cure（心配）で「心配から離れた」→「安全な」です。security も同じです。
  • seed や seem などの se は接頭語ではありません。

語源に se- をもつ単語5語

下線が接頭語の部分です。単語を選ぶと語源の説明が見られます。

  • security安全、警備
  • select～を選ぶ、選抜する
  • separate～を分ける、引き離す
  • secure～を確保する、手に入れる
  • segregate～を差別分離する

object の語源

ob〜に向かってject投げる

  1. 直訳

    向かって投げ出されたもの

  2. つまり

    目の前に置かれ、心が向かうもの

  3. 今の意味

    物・対象

同じ「投げる」の仲間
  • project計画前へ投げ出した案
  • reject拒絶する投げ返す
  • inject注射する中へ投げ入れる

部品の解説ob-接頭語

くわしく

中世ラテン語 objectum（目の前に投げ出されたもの）から。obicere（前に投げる・反対する）＝ ob（〜に向かって・逆らって）＋ iacere（投げる）。動詞「反対する」は「異議を前に投げ出す」ことから。

意味と例文

  1. 名詞物、物体入試で最多 83%

    There was a strange object in the sky.空に奇妙な物体があった。

  2. 名詞（感情・行為の）対象入試で9%

    the object of ～～の対象

    She became the object of everyone's attention.彼女は皆の注目の的になった。

  3. 名詞目的、目標入試で1%

    The object of the game is to score goals.そのゲームの目的は得点することだ。

    目指して向かう先 → 目的

  4. 動詞～に反対する入試で5%

    object to ～

    Many parents objected to the new rule.多くの親がその新しい規則に反対した。

    異議を投げつける → 反対する

派生語（形容詞形）

  • objection名詞反対、異議

  • objective形容詞客観的な

    object ＋ -ive

    Try to give an objective opinion.客観的な意見を述べるようにしなさい。

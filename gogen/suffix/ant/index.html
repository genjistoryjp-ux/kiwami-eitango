形容詞・名詞を作る接尾語

-ant / -ent の意味

動詞のうしろに付いて「〜している」という形容詞や、「〜する人」という名詞を作ります。

意味
〜している・〜する人
品詞
形容詞・名詞を作る
形
-ant -ent
  • 形容詞：depend → dependent、differ → different、consist → consistent。
  • 名詞（人）：assist → assistant、consult → consultant、account → accountant。
  • -ent も人を表すことがあります。student（学生）、resident（住民）、president。
  • 名詞形は -ance / -ence です。different → difference、dependent → dependence。

-ant / -ent が付いてできる単語15語

左が元の単語、右が接尾語の付いた単語です。

  • depend→dependent形容詞頼っている、依存した
  • account→accountant名詞会計士
  • serve→servant名詞使用人、召し使い
  • consult→consultant名詞顧問、コンサルタント
  • differ→different形容詞違った、異なる
  • consist→consistent形容詞一貫した、矛盾のない
  • persist→persistent形容詞粘り強い、しつこい、持続する
  • urge→urgent形容詞緊急の、差し迫った
  • assist→assistant名詞助手、アシスタント
  • vary→variant名詞変種、異形、（ウイルスの）変異株
  • indulge→indulgent形容詞甘い、寛大な
  • transcend→transcendent形容詞超越的な、並外れた
  • diverge→divergent形容詞異なる、分岐する
  • revere→reverent形容詞敬虔な、うやうやしい
  • inhabit→inhabitant名詞住民、生息動物

どの意味で出たか

入試の英文に出てきた application 227か所のうち129文を、1文ずつどの意味か調べました。いちばん多いのは2「応用、適用」で、44%です。

  • 3名詞（スマホなどの）アプリ22%
  • 上の意味以外（熟語など）2%

application の語源

ap〜へplic折るationこと

  1. 元の意味

    〜にくっつけること

  2. つまり

    自分や知識を何かに当てる

  3. 今の意味

    申し込み・応用

同じ「折り重ねる」（plic / ply）の仲間
  • complicated複雑な共に折り重なった
  • implyほのめかす中に折り込む
  • explicit明白な外へ広げて見せた

部品の解説ap-接頭語-ation名詞を作る

くわしく

ラテン語 applicatio から。applicare（くっつける・当てる）は ad（〜へ）＋ plicare（折り重ねる）。

意味と例文

  1. 名詞申し込み、応募（書類）入試で33%

    an application for ～～への申し込み［応募］

    I sent my application to three universities.私は3つの大学に出願書類を送った。

  2. 名詞応用、適用入試で最多 44%

    This invention has many practical applications.この発明には実用的な応用例が多い。

  3. 名詞（スマホなどの）アプリ入試で22%

    I downloaded a new application for studying.勉強用の新しいアプリをダウンロードした。

    用途に当てたソフト → アプリ

派生語（動詞形）

  • 動詞形apply申し込む
  • apply動詞（for）申し込む、～を適用する

    She applied for a job at the bank.彼女は銀行の仕事に応募した。

  • applicant名詞応募者、志願者

    There were 200 applicants for the position.その職には200人の応募者がいた。

  • appliance名詞（家庭用）電気器具

    apply ＋ -ance

    We bought new kitchen appliances.私たちは新しい台所用の電化製品を買った。

explicit と implicit の違い

explicit は「はっきり示された」、implicit は「はっきり言わず暗に示された」で、反対の意味です。

explicit

/ɪksplɪ́sət/イクスプリスィット

入試33本

  • 形容詞明確な、明示的な入試で最多
  • 形容詞露骨な、あからさまな

implicit

/ɪmplɪ́sət/インプリスィット

入試22本

  • 形容詞暗黙の、暗に示された入試で最多
  • 形容詞絶対的な、無条件の

見分けるポイント

  1. explicit は言葉や文書で明示されていること。explicit instructions「明確な指示」。
  2. be explicit about ～「～についてはっきり言う」。副詞は explicitly「明確に」。
  3. implicit は言葉にせず含まれていること。an implicit rule「暗黙のルール」。be implicit in ～ の形も。
  4. implicit trust は「絶対的な信頼」。explicit は描写が「露骨な」の意味にもなる。
覚え方ex＝外に出して示す、im（in）＝中に含む。

例文で比べる

同じ場面で使い分けると、こうなります。

  • explicit

    The teacher gave us explicit instructions not to use phones.

    先生は携帯電話を使わないようにと明確な指示を出した。
  • implicit

    There was an implicit rule that nobody used phones in class.

    授業中は誰も携帯電話を使わないという暗黙のルールがあった。

アプリの例文

  • implicit形容詞暗黙の、暗に示された

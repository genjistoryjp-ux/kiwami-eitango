fair と fare の違い

fair は「公平な」「見本市」、fare は「（乗り物の）運賃」で、発音は同じです。

fair

/féər/フェア

入試164本

  • 形容詞公平な、公正な入試で最多
  • 形容詞かなりの、相当な
  • 形容詞色白の、（髪が）金髪の

fare

/féər/フェア

入試35本

  • 名詞運賃、料金入試で最多
  • 動詞やっていく

見分けるポイント

  1. 発音はどちらも /féər/ で同じ。聞き取りでは文脈で区別する。
  2. fair は形容詞「公平な、公正な」が中心。名詞では「博覧会、見本市」（a book fair）。
  3. fare は乗り物の運賃。a bus fare、a taxi fare。商品の値段は price、サービスの料金は fee。
  4. fair には「（数量が）かなりの」の意味もある。a fair number of ～「かなりの数の～」。
覚え方fare は「行く」が語源（farewell の fare）。行くための料金。

例文で比べる

同じ場面で使い分けると、こうなります。

  • fair

    It is fair to split the cost equally.

    費用を均等に分けるのが公平だ。
  • fare

    We split the taxi fare equally.

    私たちはタクシー代を均等に分けた。

アプリの例文

  • fair形容詞公平な、公正な

    It isn't fair that only I have to clean.私だけが掃除しなければならないなんて不公平だ。

  • fare名詞運賃、料金

    The bus fare went up to 250 yen.バスの運賃が250円に上がった。

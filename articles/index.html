受験英語の記事

入試の英文を数えたデータをもとにした、英単語と受験英語の記事です。

  • まぎらわしい英単語の見分け方｜入試の英文に両方よく出る20組affect と effect、raise と rise など、まぎらわしい英単語236組を、2語とも大学入試の何本に出たかで並べました。両方よく出る20組を、1～2字ちがい、自動詞と他動詞、意味が近い、部品が同じの4種類に分けて、見分け方を紹介します。
  • 長文の流れをつかむ「つなぎの言葉」21語｜入試に出た本数で見るalthough・therefore・indeed など、文と文の関係を示す21語が大学入試1,588本と共通テスト12本に何本出たかを数えました。逆接・追加・結果・言い換え・対比・条件の役割ごとに整理し、空所補充と内容一致での使い方もまとめます。
  • 名前のない感情を表す英単語38｜あるあるな気持ちの珍しい呼び名雨のにおいは petrichor、空腹でイライラするのは hangry。だれもが感じるのに名前を知らない気持ちや瞬間を表す英単語38語を、読み方と意味、ふだんどれくらい使うかといっしょに紹介します。
  • hardly・rarely・seldom・barely・scarcely のちがい｜程度の否定と頻度の否定「ほとんど〜ない」とまとめて覚えがちな hardly・scarcely・barely と rarely・seldom を、程度の否定と頻度の否定に分けて解説。大学入試1,588本で出た本数、倒置の形、barely の「かろうじて」、部分否定の not necessarily・not entirely まで、和訳と内容一致でまちがえやすい点をまとめました。
  • 医学部・医療系の入試英語に多い英単語｜15校126本をほかの大学と比較医科大学・薬科大学など医療系15校の入試126本と、ほかの大学入試1,462本で、受験英単語の出かたを比べました。physician や chronic のような医療の語、consent や insurance のような制度の語、設問で使う infer、どの大学でも出る体と病気の語を表にまとめています。
  • カタカナ語の意味で読むとまちがえる英単語｜manner・image・address の入試での意味manner は「マナー」より「方法」、image は「イメージ」より「像、画像」。大学入試の英文を1文ずつ調べると、カタカナ語として知っている意味より、ほかの意味で多く使われていた英単語がありました。14語を文の数つきで紹介します。
  • 旧帝大の英単語レベル｜7大学の入試で比べた英文の難しさと多い単語北大・東北大・東大・名大・京大・阪大・九大の英語の入試56本を、ほかの大学の入試と比べました。上位5,000語の外の語の割合と、bond・abstract・hypothesis など、ほかの大学より多かった単語の読み方をまとめています。
  • 変な英単語44｜面白い・珍しい・長い英単語と、どこで使うか靴ひもの先は aglet、人を窓から投げ出すことは defenestration。辞書にのっている変な英単語44語を、体の部分、記号、恐怖症、45文字の長い単語などのテーマに分けて、読み方・意味・使う場面といっしょに紹介します。
  • フォニックスのルール一覧｜受験英単語で数えた、つづりと読み方マジック e（a-e など）や ee・ay は9割以上がルールどおりでしたが、ea・ow は読み方が分かれました。フォニックス（つづりと発音のルール）が受験英単語3,467語のうち何語に当てはまるかを数え、例外とあわせてまとめます。
  • 心理学の長文によく出る英単語｜入試で出た本数と英文の型behavior は大学入試1,588本の28.5%に出る一方、cognition や instinct は令和6〜8年度の共通テスト12本に1本も出ていません。記憶・習慣・感情・動機・思い込みを扱う心理学の英文に出る語を出た本数で並べ、実験→結果→解釈という英文の型と、perceive・bias・reward などの読み方をまとめます。
  • 理系の長文に出る英単語｜生き物・環境・宇宙の語を入試データでspecies・climate・planet など、生き物・環境・宇宙の英単語23語が大学入試1,588本と共通テスト12本に何本出たかを表にし、どんな話題の英文で出るかをテーマ別にまとめました。理工系11校の入試113本で、ほかの大学より多く出た語も紹介します。
  • 入試の英文はこの数年でどう変わった？｜2020〜2026年度で増えた英単語・減った英単語大学入試1,588本を年度で分け、2020・2021年度と2025・2026年度で英単語の出かたを比べました。pandemic、artificial、diversity など増えた語、climate のように変わらない語、youth や injure のように減った語を、年度ごとの数字で紹介します。
  • 語根で覚える英単語｜入試に多い20の語根と、まぎらわしい語の見分け方spect（見る）、fer（運ぶ）、tend（伸ばす）など、英単語の真ん中にある語根を、見出し語10語以上に共通する26個から大学入試での本数順に20個並べました。accept と except、consist と insist など、まぎらわしい組を語根で見分ける方法も紹介します。
  • 英単語の派生語は覚えるべき？入試に多い派生語と覚え方differ より different、respond より response のほうが多くの入試に出ていました。大学入試1,588本で見出し語と派生語を比べ、語尾で品詞を見分ける方法、否定の接頭辞、覚え方をまとめます。
  • 英単語の意外な意味｜入試では最初に覚える訳より多く出る意味demand は「需要」、field は「分野」。大学入試の英文を1文ずつ調べると、まず思い浮かぶ訳よりほかの意味のほうがずっと多く使われていた英単語が283語ありました。ずれ方のパターン別に、文の数つきで紹介します。
  • 大学受験に必要な英単語は何語？入試の英文を数えてわかった目安国公立・私立の大学入試1,588本に出た語を多い順に並べ、上位何語で共通テスト・国立・公立・私立の英文の何%が読めるかを計算しました。95%に届くのは共通テストで約3,800語、国立で約5,000語です。
  • 英単語の覚え方｜受験生が忘れずに覚える手順を入試データで解説受験生向けの英単語の覚え方。大学入試1,588本で単語の出かたを数えたデータをもとに、覚える順番、1つの意味から始める理由、思い出す練習と復習の間隔、1日の量の決め方、覚えたかの確かめ方まで説明します。
  • 共通テストと二次・私大で出る英単語のちがい｜入試データで比較共通テスト12本と大学入試1,588本で、受験英単語4,104語の出かたを比べました。共通テストに多い語、共通テストには出ないのに二次・私大でよく出る語、国立と私立で多い語を表にまとめ、覚える順番も紹介します。
  • MARCH・関関同立の英単語レベル｜大学別の難しさと出る単語MARCH・関関同立の9大学の入試英語に、めったに出ない語がどれだけ出るかを大学別に数えました。同志社・明治・関西学院の差、会話文の語、グループごとに多い単語、大学別の対策まで。
  • 英語の多義語の覚え方｜入試の長文で本当に使われる意味は？英語の多義語の覚え方を、大学入試の英文で1文ずつ意味を調べたデータで解説。yet・still・hold など長文でよく使われる意味と、めったに出ないが知っておきたい意味に分けて紹介します。
  • 早稲田・慶應の英単語レベル｜入試の英文で比べた難しさと頻出語早稲田・慶應・上智の入試の英文に、ほかの大学の入試で上位5,000語に入らない語が何%あるかを数え、国立や共通テストと比べました。早慶でとくに多い単語と、1冊目を終えたあとの広げ方も紹介します。

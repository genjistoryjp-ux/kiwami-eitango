名詞を作る接尾語

-er / -or の意味

動詞のうしろに付いて名詞を作ります。「〜する人」や「〜する道具・機械」を表します。

意味
〜する人・もの
品詞
名詞を作る
形
-er -or
  • teach → teacher、employ → employer（雇い主）、browse → browser。
  • -or の形もあります。act → actor、advise → advisor、calculate → calculator。
  • employer（雇う人）と employee（雇われる人）の区別がよく問われます。
  • 比較級の -er（taller）や、error, corner の er とは別のものです。

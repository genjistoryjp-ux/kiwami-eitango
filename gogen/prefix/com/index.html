「共に・すっかり」の接頭語

con- / com- / col- / cor- / co- の意味

動詞や名詞の前に付いて「共に」「いっしょに」「すっかり」の意味を加えます。後ろの文字で形が変わります。

意味
共に・すっかり
形
con- com- col- cor- co-
  • b, m, p の前では com- になります。combine, commit, compare。
  • l の前では col-、r の前では cor- になります。collect, correct。
  • 母音や h の前では co- になります。cooperate, coexist, coauthor。
  • contain（含む）は「共に保つ」、connect（つなぐ）は「共に結ぶ」です。

con- / com- が付いてできる単語3語

左が元の単語、右が接頭語の付いた単語です。

  • operate→cooperate動詞協力する
  • exist→coexist動詞共存する
  • author→coauthor名詞共著者

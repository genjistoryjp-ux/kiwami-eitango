共通テストと二次・私大で出る英単語のちがい｜入試データで比較

2026年10月30日

共通テストで目立つ英単語と、国公立の二次試験や私大で目立つ英単語は、顔ぶれがちがいます。入試の英文で数えた回数をもとに、そのちがいと覚える順番をまとめました。

同じ受験英単語でも、共通テストでよく見る語と、二次試験や私大の問題でよく見る語は同じではありません。共通テストでは、イベントの案内や予定、レビュー、メールのような、生活や実務の英語に出てくる語が目立ちます。二次・私大では、研究や社会の問題を論じる文章の語が増え、その中には共通テストに一度も出てこなかった語もあります。さらに、国立と私立でも、多く出る話題が少しずつちがいます。

この記事では、受験英単語2,500語が実際の入試の英文に何回出たかを、共通テストと大学入試（国立・公立・私立）で比べました。最後に、受ける試験に合わせた覚える順番を紹介します。

比べた英文：共通テストは令和6〜8年度の本試験・追試験で、リーディングとリスニングの読み上げ英文を別々に数えた12本です。大学入試は国公立・私立の大学入試（2020〜2026年度）で、国立566本、公立165本、私立445本の計1,176本です。英文の量がちがうので、回数は「10万語あたり」にそろえました（3文字以上の語で数えて、共通テスト36,129語、国立933,040語、公立286,698語、私立923,696語）。変化形は見出しの語とまとめて数えています（predict なら predicts・predicted・predicting も含みます）。went のような不規則な形は含めていません。

共通テストで目立つ英単語

まず、共通テスト12本のうち5本以上に出た206語について、10万語あたりの回数が大学入試の何倍になるかを出し、大きい順に並べました。上位15語です。

1位の outline は、共通テストでは10万語あたり72.0回、大学入試では2.4回で、約30倍の差があります。comment は約20倍、option は9倍です。

並んだ語を見ると、共通テストにどんな英文が多いかが見えてきます。register（登録する、申し込む）、arrange（手配する）、schedule（予定）、event（行事、催し）、resident（住民）、local（地元の）は、講座やイベントの案内、町のお知らせ、旅行の予定といった英文でおなじみの語です。comment と opinion はレビューや投稿、option はいくつかの案を比べて選ぶ場面でよく使われます。表の下にも staff（職員）、prepare、activity、satisfy、item（品物、項目）が続き、同じ傾向です。

共通テストのリーディングは設問や選択肢も英語で、事実（fact）と意見（opinion）を見分ける問いや、発表用のメモやアウトラインを完成させる問いもおなじみです。outline、comment、opinion はリーディング6本のすべてに出ていて、リスニングには出ていません。本文だけでなく、設問を読むための語としても押さえておきましょう。一方、リスニングの読み上げ英文6本では、schedule が3本、event と local が4本に出ています。こうした語は、聞いてすぐ意味がわかるように音でも覚えておきたいところです。

なお、共通テストは12本を合わせても、数えた語が約3.6万語と多くないので、register のように7回しか出ていない語も上位に入ります。また、共通テストで目立つ語が二次・私大で出ないわけではありません。event は大学入試1,176本のうち361本、local は368本に出ています。共通テストのために覚えた語は、二次・私大でもそのまま役に立ちます。

共通テストに一度も出ず、大学入試で200本以上に出た語

反対に、共通テスト12本には一度も出なかったのに、大学入試ではよく出る語もあります。2,500語のうち、共通テストで0本、大学入試で150本以上という語は30語を超えます。そのうち、200本以上に出た主な語がこちらです。

いちばん上の force は、大学入試1,176本のうち390本、だいたい3本に1本の割合で出ているのに、共通テストでは1回も出ていません。

これらは、研究や社会について筆者が意見を述べる論説文でよく使われる語です。theory（理論）、predict（予測する）、structure（構造）、expert（専門家）は研究を紹介する文章の定番です。increasingly（ますます）は社会の変化や傾向を述べるときに、indeed（実際、それどころか）は前の内容を強めたり、さらに一歩進めたりするときに使われる、論説文らしい副詞です。force や fail のように身近に見える動詞も、論説文では be forced to do（〜せざるをえない）、fail to do（〜しない、〜できない）の形でよく使われます。

150〜199本の語にも、assume（思い込む、仮定する：199本）、intelligence（知能：192本）、context（背景、文脈：184本）、phenomenon（現象：155本）のような論説文らしい語や、largely（主に：164本）、necessarily（必ずしも：162本）、entirely（完全に：157本）、significantly（著しく：157本）のように、程度や範囲を表す副詞が並びます。not necessarily（必ずしも〜とは限らない）や not entirely（完全に〜というわけではない）は部分否定なので、内容一致や和訳で取りちがえやすいところです。

共通テストは量が少ないので、たまたま出なかっただけの語もあるはずです。それでも、論説文の語がこれだけまとまって0本なのは、共通テストと二次・私大で英文の種類がちがうためと考えられます。共通テスト向けの単語練習だけを続けていると、このグループが手薄になります。

国立と私立で多い語のちがい

大学入試の中でも、国立と私立では多い語に差があります。公立は165本と少ないので、ここでは国立と私立を比べました。国立と私立を合わせて150回以上出た669語について、国立の10万語あたりの回数が私立の何倍か（私立で多い語はその逆）を出し、差が大きい主な語を並べています。

私立では、purchase（購入する）が国立の2.6倍、customer（客）が2.5倍です。customer、purchase、property（財産）、competition（競争）、project（計画、事業）、labor（労働）のような商売や経済の語、religious（宗教の）、revolution（大変革、革命）のような歴史や社会の語、fiction（小説）のような物語の語が目立ちます。

一方、suitable（適した）、imply（ほのめかす）、except（〜を除いて）、otherwise（さもないと、その他の点では）は、特定の話題の語ではありません。except と otherwise は、例外や「そうでなければ」という条件を示して論理の筋道をつくる語です。suitable と imply は、Choose the most suitable answer.（最も適切な答えを選べ）や What does the author imply?（筆者は何をほのめかしているか）のように、英語で書かれた設問でもよく見かける語です。

表を見るときは、本数の列もあわせて見てください。revolution は国立48本、私立47本と、出た本数はほとんど同じです。1本の長文で同じ語がくり返し使われると、回数の差は大きく出ます。また、差がいちばん大きい語でも3倍ほどで、片方にしか出ないわけではありません。evidence は私立445本のうち124本に、customer は国立566本のうち70本に出ています。志望校の種類で覚えない語を決めるのではなく、どちらを先に固めるかの目安にしてください。

受ける試験に合わせた覚える順番

ここまでの結果をもとに、覚える順番の目安をまとめます。どちらの場合も、土台になるのは試験の種類を問わず広く出る基本の語で、そこから先の広げ方が変わります。

共通テストが中心の人

  1. 大学入試全体でよく出る基本の語を先に固める。
  2. 共通テストで目立つ語（option、register、arrange、schedule など）を、案内やメールの英文の中で覚える。register for a course（講座に申し込む）、reply to an email（メールに返信する）、local residents（地元の住民）のように、場面でよく使う組み合わせごと覚えると、本番で読む速さが上がります。
  3. schedule や event のようにリスニングにも出る語は、音声で確認する。
  4. 余裕が出てきたら、論説文の語（theory、predict など）にも進む。長めの記事や説明文を落ち着いて読むための土台になります。

二次・私大まで受ける人

  1. 基本の語を固める。
  2. 夏までに、共通テストには出なかった論説文の語（theory、assume、context、increasingly など）に手をつける。秋以降は共通テスト形式の演習に時間を取られやすく、ここを後回しにすると、二次・私大の過去問に取りかかってから語彙の不足に気づいても、取り戻す時間があまり残っていません。
  3. 志望校に合わせて話題の語を足す。国立が中心なら医療・科学・心理の語（patient、evidence、bias、anxiety など）、私立が中心なら経済・社会の語（customer、purchase、competition など）と、設問でよく見る suitable や imply、論理の筋道をつくる except や otherwise を優先します。
  4. 共通テストで目立つ語は、共通テストの過去問を解きながら仕上げる。具体的な場面で使う語が多いので、問題の中で出会うと覚えやすくなります。

単語は、実際の英文の中で何度も出会うことで定着していきます。どの順番で進める場合も、覚えた語を過去問や長文の中で見つけて、意味をすぐに思い出せるか確かめていきましょう。

「外へ」の接頭語

ex- / e- / ef- の意味

動詞などの前に付いて「外へ」「外に」の意味を加えます。export（輸出する）は「外へ運ぶ」です。

意味
外へ
形
ex- e- ef-
  • f の前では ef- になります。effect, effort。
  • b, d, g, l, m, n, v などの前では e- だけになります。educate, evident, emerge。
  • import ⇔ export、include ⇔ exclude、inhale ⇔ exhale のように in- と対になります。
  • ex-wife（元妻）のようにハイフン付きで「前の・元の」の意味にもなります。
